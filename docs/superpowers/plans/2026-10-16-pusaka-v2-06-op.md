> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Alur kerja kampus lengkap di peramban — operator BAAK mengunggah draf (CSV + PDF), Rektor menandatangani EIP-712 atau menolak, operator mencatat batch ke kontrak dan mencetak lembar QR berkunci, lalu alur pencabutan — teruji E2E terhadap kontrak, API Rust, dan Postgres asli.

**Architecture:** Semua island halaman dalam dibungkus `PenyediaSesi` (Privy di produksi; akun Anvil saat build `PUBLIC_MODE_UJI=1`) dan `Penjaga` (membaca `/api/sesi`, mewajibkan peran). Logika murni (klien API, data EIP-712, calldata transaksi, penyiapan amplop + metadata, pemetaan status) ada di `src/lib` dan diuji Vitest dengan WASM asli. Operator memakai jendela perintah gaya Raycast (`Jendela`), pejabat memakai meja gaya Quantum. E2E menjalankan `pusaka-api` asli dengan kunci verifikasi JWT uji, tiruan Privy REST + Pinata, dan Postgres Docker.

**Tech Stack:** Astro 7 + React 19 (`client:only`), @privy-io/react-auth 3.49 (hook headless: `useLoginWithOAuth`, `useLoginWithEmail`, `useLoginWithSiwe`, `useWallets`), viem 2.57, uqr (QR SVG lokal), EIP-6963, WebCrypto (JWT uji), Vitest, Playwright, Rust `pusaka-api`, Docker Postgres.

**Spec:** `docs/superpowers/specs/2026-10-16-pusaka-v2-design.md` (bagian 4, 7.2, 8.1, 8.3, 8.4, 9 Penerbitan & Pencabutan, 10)

**Branch:** `feat/pusaka-v2-op` dari `feat/pusaka-v2-periksa`; PR ke `feat/pusaka-v2-periksa`.

## Global Constraints

- Login memakai hook headless Privy dengan UI kustom dua panel (spec 8.3), bukan modal bawaan; kecuali "Wallet lain (WalletConnect)" yang memakai `login({ loginMethods: ['wallet'] })`.
- Tanda tangan pejabat: EIP-712 domain `PUSAKA` v`2`, `chainId`, `verifyingContract`; batas waktu bawaan 7 hari.
- Operator dan pejabat memakai wallet berbeda (kontrak menolak `penandaTangan == msg.sender`).
- Kunci AES dibuat di peramban operator (32 byte acak), amplop disegel `pusaka-core.wasm`, metadata publik tanpa data pribadi (spec 6.2).
- Status selalu kata + simbol + warna; semua aksi operator bisa dengan keyboard (↑/↓, ↵, ⌘K/Ctrl+K, `/`, ⌘↵ di unggah; ↵ dan X di meja).
- Build uji (`PUBLIC_MODE_UJI=1`) hanya untuk E2E; API produksi memverifikasi token dengan kunci Privy sehingga token uji ditolak.
- `npm --prefix web run check` 0 galat; tanpa atribusi AI.

## Keputusan terhadap spec

1. **Wallet luar lewat EIP-6963 + SIWE Privy** (`generateSiweMessage` → `personal_sign` → `loginWithSiwe`), supaya panel kanan kustom tanpa modal Privy. WalletConnect memakai modal Privy sebagai cadangan.
2. **`/op/peran` (kelola peran admin) ditunda** ke rencana 09 (serah-terima admin): peran diberikan lewat `cast`/explorer saat deploy.
3. **Gambar metadata = `<situs>/segel.svg`**, bukan CID IPFS terpisah; isinya statis dan tidak memuat data pribadi.
4. **Privy 3.49 + viem 2.57:** konflik peer opsional `ox` diselesaikan dengan `overrides: { permissionless: "0.5.0" }`, bukan `legacy-peer-deps` (yang membuat `@astrojs/check` gagal dimuat).
5. **Kurung `‹ ›` tombol diberi teks alternatif kosong** (`content: "‹" / ""`) supaya nama aksesibel tombol hanya kata kerjanya.

## Review Focus

1. Operator membuka `/meja` (atau pejabat membuka `/op`) → layar "Halaman ini untuk …", tidak ada aksi (E2E `operator tidak bisa membuka meja tanda tangan`).
2. Baris CSV tidak sah / PDF hilang → ditandai per baris dan tidak ikut terkirim (E2E unggah: baris 4 `nim`).
3. Parameter `?ke=` setelah masuk menunjuk situs lain → diabaikan (unit `tujuanAman`).
4. Tanda tangan dari peramban harus identik dengan kontrak (unit `eip712`: viem = vektor bersama = `pusaka-core`).
5. Batch terbit > 50 atau draf tanpa tanda tangan → ditolak sebelum transaksi (unit `transaksi`).

```ts
import { createServer, type IncomingMessage, type Server } from 'node:http';
import type { AddressInfo } from 'node:net';

async function bacaBadan(req: IncomingMessage): Promise<string> {
  const bagian: Buffer[] = [];
  for await (const b of req) bagian.push(b as Buffer);
  return Buffer.concat(bagian).toString('latin1');
}

beforeAll(async () => {
  server = createServer(async (req, res) => {
    diterima.push({
      metode: req.method ?? '',
      url: req.url ?? '',
      auth: req.headers.authorization ?? '',
      jenis: req.headers['content-type'] ?? '',

    res.end('{"ok":true}');
```

```ts
import { readFileSync } from 'node:fs';
import type { Hex } from 'viem';
import { beforeAll, expect, test } from 'vitest';
import { tautanBerkunci } from '../src/lib/tautan';
import { cocokkanPdf, siapkanDraf, type AlatUnggah } from '../src/lib/unggah';

beforeAll(() => {

const DATA = { nama: 'Dewi', nim: '2310/114', prodi: 'TI', gelar: 'S.Kom.', nomor_ijazah: 'N1', tanggal_lulus: '2026-08-30' };

function alat() {
  const ipfs = new Map<string, Uint8Array>();
  const a: AlatUnggah & { ipfs: Map<string, Uint8Array>; nama: string[] } = {
    ipfs,
    nama: [],
    keccak: (b) => keccak256_hex(b) as Hex,
    segel: segel_amplop,
    acak: (n) => crypto.getRandomValues(new Uint8Array(n)),
    gambar: 'https://pusaka.example/segel.svg',
    async unggah(nama, isi) {
      const cid = `cid${ipfs.size}`;
      ipfs.set(cid, isi);
      a.nama.push(nama);
      return { cid, uri: `ipfs://${cid}` };
    },
  };
  return a;
}

test('draf siap: sidik jari, amplop yang bisa dibuka dengan kunci, metadata tanpa data pribadi', async () => {
  const pdf = new TextEncoder().encode('%PDF ijazah Dewi');
  const a = alat();
  const d = await siapkanDraf(DATA, 'dewi@unpam.ac.id', pdf, a);
  expect(d.doc_hash).toBe(keccak256_hex(pdf));
  expect(d.kunci).toMatch(/^0x[0-9a-f]{64}$/);
  expect(a.nama).toEqual(['amplop-2310114.bin', 'meta-2310114.json']);

  const kunci = Uint8Array.from(Buffer.from(d.kunci.slice(2), 'hex'));
  const h = buka_amplop(kunci, a.ipfs.get(d.cid_amplop) ?? new Uint8Array());
  expect(JSON.parse(h.data_json)).toEqual(DATA);
  expect(h.pdf).toEqual(pdf);
  h.free();

  const meta = new TextDecoder().decode(a.ipfs.get(d.uri.slice(7)));
  expect(JSON.parse(meta).pusaka).toEqual({ versi: 2, berkas: `ipfs://${d.cid_amplop}`, doc_keccak256: d.doc_hash, enkripsi: 'AES-256-GCM' });
  expect(meta).not.toContain('Dewi');
  expect(meta).not.toContain('2310');
});
```

```ts
import type { Address, Hex } from 'viem';

export interface Peran {

export interface InfoSesi {
  did: string;
  wallet: Address[];
  peran: Peran;
}

export function buatApi(token: () => Promise<string>, dasar = ''): Api {
  async function minta<T>(metode: string, jalur: string, badan?: BodyInit, jenis?: string): Promise<T> {
    const headers: Record<string, string> = { authorization: `Bearer ${await token()}` };
    if (jenis) headers['content-type'] = jenis;
    const r = await fetch(`${dasar}${jalur}`, { method: metode, headers, ...(badan === undefined ? {} : { body: badan }) });
    const teks = await r.text();
    let isi: unknown = null;
    try {
      isi = teks ? JSON.parse(teks) : null;
    } catch {
      // badan bukan JSON (mis. halaman galat proxy)
    }
    if (!r.ok) {
      const g = isi as { kode?: unknown; pesan?: unknown } | null;
      throw new GalatApi(
        r.status,
        typeof g?.kode === 'string' ? g.kode : 'GALAT',
        typeof g?.pesan === 'string' ? g.pesan : `Server menjawab ${r.status}`,
      );
    }
    return isi as T;
  }
  const json = <T,>(metode: string, jalur: string, badan: unknown) =>
    minta<T>(metode, jalur, JSON.stringify(badan), 'application/json');
  const kueri = (q: Record<string, string | number | undefined>) => {
    const p = new URLSearchParams();
    for (const [k, v] of Object.entries(q)) if (v !== undefined && v !== '') p.set(k, String(v));
    const s = p.toString();
    return s ? `?${s}` : '';
  };

  return {
    sesi: () => minta('GET', '/api/sesi'),
    unggahIpfs: (nama, isi) =>
      minta('POST', `/api/ipfs${kueri({ nama })}`, isi.slice(), 'application/octet-stream'),
    buatDraf: (draf) => json('POST', '/api/draf', { draf }),
    daftarDraf: (q = {}) => minta('GET', `/api/draf${kueri({ status: q.status, cari: q.cari, halaman: q.halaman })}`),
    detailDraf: (id) => minta('GET', `/api/draf/${encodeURIComponent(id)}`),
    setujui: (id, sig, batasWaktu) =>
      json('POST', `/api/draf/${encodeURIComponent(id)}/setujui`, { sig, batas_waktu: Number(batasWaktu) }),
    tolak: (id, alasan) => json('POST', `/api/draf/${encodeURIComponent(id)}/tolak`, { alasan }),
    kirimUlang: (id, draf) => json('POST', `/api/draf/${encodeURIComponent(id)}/kirim-ulang`, draf),
    terbit: (txHash) => json('POST', '/api/terbit', { tx_hash: txHash }),
    mintaCabut: (tokenId, alasan) => json('POST', '/api/cabut', { token_id: tokenId, alasan }),
    daftarCabut: (status) => minta('GET', `/api/cabut${kueri({ status })}`),
    setujuiCabut: (id, sig, batasWaktu) =>
      json('POST', `/api/cabut/${encodeURIComponent(id)}/setujui`, { sig, batas_waktu: Number(batasWaktu) }),
    selesaiCabut: (id, txHash) => json('POST', `/api/cabut/${encodeURIComponent(id)}/selesai`, { tx_hash: txHash }),
    kunci: (tokenId) => minta('GET', `/api/kunci/${tokenId}`),
  };
}
```

```ts
//! Calldata transaksi yang dikirim wallet operator.

import { encodeFunctionData, parseAbi, type Hex } from 'viem';
import type { Draf, PermintaanCabut } from './api';

export const MAKS_BATCH = 50;

export const abiTulis = parseAbi([
  'struct Penerbitan { address penerima; bytes32 docHash; bytes32 metadataHash; uint64 batasWaktu; }',
  'struct Pencabutan { uint256 tokenId; bytes32 alasanHash; uint64 batasWaktu; }',
  'function terbitkanBatch(Penerbitan[] p, bytes[] sig, string[] uri)',
  'function cabut(Pencabutan c, bytes sig, string alasan)',
]);

/** `terbitkanBatch` untuk draf yang sudah ditandatangani dan tanda tangannya masih berlaku. */
export function dataTerbitkan(daftar: Draf[]): Hex {
  if (daftar.length === 0 || daftar.length > MAKS_BATCH) {
    throw new Error(`Satu transaksi memuat 1–${MAKS_BATCH} ijazah`);
  }
  const p = [];
  const sig: Hex[] = [];
  const uri: string[] = [];
  for (const d of daftar) {
    if (!d.ttd) throw new Error(`Draf ${d.nama} belum ditandatangani`);
    p.push({ penerima: d.penerima, docHash: d.doc_hash, metadataHash: d.metadata_hash, batasWaktu: BigInt(d.ttd.batas_waktu) });
    sig.push(d.ttd.sig);
    uri.push(d.uri);
  }
  return encodeFunctionData({ abi: abiTulis, functionName: 'terbitkanBatch', args: [p, sig, uri] });
}

export function dataCabut(c: PermintaanCabut): Hex {
  if (!c.ttd) throw new Error('Permintaan cabut belum ditandatangani pejabat');
  return encodeFunctionData({
    abi: abiTulis,
    functionName: 'cabut',
    args: [{ tokenId: BigInt(c.token_id), alasanHash: c.alasan_hash, batasWaktu: BigInt(c.ttd.batas_waktu) }, c.ttd.sig, c.alasan],
  });
}
```

```ts
function namaBerkas(awalan: string, nim: string, akhiran: string): string {
  return `${awalan}-${nim.replace(/[^0-9A-Za-z]/g, '') || 'x'}.${akhiran}`;
}

/** Segel amplop dan unggah amplop + metadata; hasilnya siap dikirim sebagai draf. */
export async function siapkanDraf(data: DataLulusan, email: string, pdf: Uint8Array, alat: AlatUnggah): Promise<DrafBaru> {
  const docHash = alat.keccak(pdf);
  const kunci = alat.acak(32);
  const amplop = alat.segel(kunci, alat.acak(12), JSON.stringify(data), pdf);
  const { cid } = await alat.unggah(namaBerkas('amplop', data.nim, 'bin'), amplop);

  const { uri } = await alat.unggah(namaBerkas('meta', data.nim, 'json'), meta);
  return { ...data, email, doc_hash: docHash, uri, cid_amplop: cid, kunci: keHex(kunci) };
}
```

```ts
  request(args: { method: string; params?: unknown }): Promise<unknown>;
}

/** Penanda dari akun lokal (uji) atau dari provider EIP-1193 (Privy tertanam / wallet luar). */

  const chain = rantaiViem(j);
  const klien = createWalletClient({ account: akun, chain, transport: provider ? custom(provider) : http(j.rpcUrl) });
  const publik = createPublicClient({ chain, transport: http(j.rpcUrl) });
  const alamat = typeof akun === 'string' ? akun : akun.address;
  return {
    alamat,
    tandaTangani: (d) =>
      d.primaryType === 'Penerbitan'
        ? klien.signTypedData({ domain: domainPusaka(j), types: TIPE_EIP712, primaryType: 'Penerbitan', message: d.message })
        : klien.signTypedData({ domain: domainPusaka(j), types: TIPE_EIP712, primaryType: 'Pencabutan', message: d.message }),
    async kirim(tx) {
      const hash = await klien.sendTransaction({ to: tx.to, data: tx.data });
      const r = await publik.waitForTransactionReceipt({ hash });
      if (r.status !== 'success') throw new Error('Transaksi ditolak kontrak (revert). Periksa tanda tangan dan batas waktunya.');
      return hash;
    },
  };
}
```

```ts
//! Token "Privy" uji, ditandatangani ES256 di peramban dengan kunci KHUSUS TES. Hanya dipakai build
//! `PUBLIC_MODE_UJI=1`; API produksi memverifikasi dengan kunci Privy asli sehingga token ini ditolak.

function b64url(b: Uint8Array | string): string {
  const s = typeof b === 'string' ? b : String.fromCharCode(...b);
  return btoa(s).replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
}

function pemKeDer(pem: string): ArrayBuffer {
  const isi = pem.replace(/-----[^-]+-----/g, '').replace(/\s+/g, '');
  return Uint8Array.from(atob(isi), (c) => c.charCodeAt(0)).buffer;
}

export async function tandaTanganJwt(klaim: Record<string, unknown>, pemPkcs8: string): Promise<string> {
  const kunci = await crypto.subtle.importKey('pkcs8', pemKeDer(pemPkcs8), { name: 'ECDSA', namedCurve: 'P-256' }, false, ['sign']);
  const kepala = b64url(JSON.stringify({ alg: 'ES256', typ: 'JWT' }));
  const isi = b64url(JSON.stringify(klaim));
  const sig = await crypto.subtle.sign({ name: 'ECDSA', hash: 'SHA-256' }, kunci, new TextEncoder().encode(`${kepala}.${isi}`));
  return `${kepala}.${isi}.${b64url(new Uint8Array(sig))}`;
}
```

```tsx
  onCari,

  chip,
  chipAktif,
  onChip,
  item,
  terpilih,
  onPilih,
  detail,

  aksiUtama,
  aksi,
  kosong,

  cari: string;
  onCari: (s: string) => void;
  petunjuk: string;
  chip: Chip[];
  chipAktif: string;
  onChip: (id: string) => void;
  item: Item[];
  terpilih: string | null;
  onPilih: (id: string) => void;

    const garis = (e: globalThis.KeyboardEvent) => {
      const mengetik = e.target instanceof HTMLInputElement || e.target instanceof HTMLTextAreaElement;
      if (e.key === '/' && !mengetik) {
        e.preventDefault();
        kotak.current?.focus();

        setMenu(false);
        a?.jalankan();

      e.preventDefault();

            if (x.grup) grupTerakhir = x.grup;
            return (
              <div key={x.id}>
                {judulGrup && <div className="hud jendela-grup">{judulGrup}</div>}

                  type="button"
                  role="option"
                  className="baris-item"
```

```js
      return DID[did] ? jawab(res, 200, pengguna(did, DID[did])) : jawab(res, 404, { error: 'User not found' });
    }
    if (req.method === 'POST' && url.pathname === '/v1/users/email/address') {
      const { address } = await json(req);
      const a = email.get(address);
      return a ? jawab(res, 200, pengguna(`did:privy:${address}`, a, [{ type: 'email', address }])) : jawab(res, 404, { error: 'User not found' });
    }
    if (req.method === 'POST' && url.pathname === '/v1/users') {
      const b = await json(req);
      const address = b.linked_accounts?.[0]?.address;
      const a = walletEmail(address);
      email.set(address, a);
      return jawab(res, 200, pengguna(`did:privy:${address}`, a, [{ type: 'email', address }]));
    }
    if (req.method === 'POST' && url.pathname === '/v3/files') {
      const form = await new Request('http://lokal/', { method: 'POST', headers: req.headers, body: Readable.toWeb(req), duplex: 'half' }).formData();
      const berkas = form.get('file');
      if (!(berkas instanceof Blob)) return jawab(res, 400, { error: 'file wajib' });
      const isi = new Uint8Array(await berkas.arrayBuffer());
```

```js
// Server statis E2E: meniru rewrite dan header vercel.json, plus "IPFS" lokal di /ipfs/<cid>.
import { readFile } from 'node:fs/promises';
import { createServer, request } from 'node:http';
import { extname, join, normalize } from 'node:path';

const DIST = new URL('../dist/', import.meta.url).pathname;
const IPFS = new URL('./.data/ipfs/', import.meta.url).pathname;
const PORT = Number(process.env.PORT ?? 4329);
const API = Number(process.env.PORT_API ?? 8799);
const JENIS = {
  '.html': 'text/html; charset=utf-8',
  '.js': 'text/javascript',
  '.css': 'text/css',
  '.wasm': 'application/wasm',
  '.woff2': 'font/woff2',
  '.woff': 'font/woff',
  '.svg': 'image/svg+xml',
};

createServer(async (req, res) => {
  // /api/* diteruskan ke pusaka-api lokal, seperti rewrite vercel.json ke fungsi Rust.
  if (req.url?.startsWith('/api/')) {
    const maju = request({ host: '127.0.0.1', port: API, path: req.url, method: req.method, headers: req.headers }, (r) => {
      res.writeHead(r.statusCode ?? 502, r.headers);
      r.pipe(res);
    });
    maju.on('error', () => {
      res.writeHead(502, { 'content-type': 'application/json' });
      res.end('{"kode":"LAYANAN_LUAR","pesan":"pusaka-api lokal tidak menyala"}');
    });
    req.pipe(maju);
    return;
  }
  let jalur = '/';
  try {
    jalur = decodeURIComponent(new URL(req.url ?? '/', 'http://lokal').pathname);
    if (jalur.startsWith('/ipfs/')) {
      const isi = await readFile(join(IPFS, jalur.slice(6).replace(/[^A-Za-z0-9]/g, '')));
      res.writeHead(200, { 'content-type': 'application/octet-stream' });
      return res.end(isi);
    }
    const header = {};
    if (/^\/i\/\d+\/?$/.test(jalur)) {
      jalur = '/i/';
      header['referrer-policy'] = 'no-referrer';
    }
    if (jalur.endsWith('/')) jalur += 'index.html';
    else if (!extname(jalur)) jalur += '/index.html';
    const berkas = normalize(join(DIST, jalur));
    if (!berkas.startsWith(DIST)) throw new Error('di luar dist');
    const isi = await readFile(berkas);
    res.writeHead(200, { 'content-type': JENIS[extname(berkas)] ?? 'application/octet-stream', ...header });
    res.end(isi);
  } catch {
    res.writeHead(404, { 'content-type': 'text/plain; charset=utf-8' });
    res.end('Tidak ditemukan');
  }
}).listen(PORT, '127.0.0.1');
```

```tsx
function pesan(e: unknown): string {

function Isi() {
  const { api, info, sesi, j } = useAplikasi();
  const [cari, setCari] = useState('');
  const [chip, setChip] = useState<'semua' | StatusDraf>('semua');
  const [daftar, setDaftar] = useState<Draf[]>([]);
  const [total, setTotal] = useState(0);
  const [hitung, setHitung] = useState<Hitungan>({ tercatat: 0, siap: 0, menunggu: 0 });
  const [terpilih, setTerpilih] = useState<string | null>(null);
  const [kabar, setKabar] = useState<{ teks: string; nada?: 'ok' | 'bad' } | null>(null);
  const [sibuk, setSibuk] = useState(false);
  const [cabut, setCabut] = useState(false);
  const [alasan, setAlasan] = useState('');
  const [qr, setQr] = useState<{ tautan: string; nama: string; nomor: string } | null>(null);

  const muat = useCallback(async () => {
    const kueri = { ...(chip === 'semua' ? {} : { status: chip }), cari };
    const [h, a, b, c] = await Promise.all([
      api.daftarDraf(kueri),
      api.daftarDraf({ status: 'TERBIT' }),
      api.daftarDraf({ status: 'DITANDATANGANI' }),
      api.daftarDraf({ status: 'MENUNGGU_TTD' }),
    ]);
    setDaftar(h.data);
    setTotal(h.total);
    setHitung({ tercatat: a.total, siap: b.total, menunggu: c.total });
    setTerpilih((t) => (t && h.data.some((d) => d.id === t) ? t : (h.data[0]?.id ?? null)));
  }, [api, chip, cari]);

  useEffect(() => {
    const t = setTimeout(() => void muat().catch((e: unknown) => setKabar({ teks: pesan(e), nada: 'bad' })), 200);
    return () => clearTimeout(t);
  }, [muat]);

  const d = daftar.find((x) => x.id === terpilih) ?? null;
  useEffect(() => {
    setCabut(false);
    setAlasan('');
  }, [terpilih]);

  async function jalankan(label: string, kerja: () => Promise<string>) {
    setSibuk(true);
    setKabar({ teks: `${label}…` });
    try {
      setKabar({ teks: await kerja(), nada: 'ok' });
      await muat();
    } catch (e) {
      setKabar({ teks: pesan(e), nada: 'bad' });
    } finally {
      setSibuk(false);
    }
  }

  const catat = () =>
    jalankan('Mengirim transaksi ke blockchain', async () => {
      const siap: Draf[] = [];
      for (let hal = 1; siap.length < MAKS_BATCH; hal++) {
        const h = await api.daftarDraf({ status: 'DITANDATANGANI', halaman: hal });
        siap.push(...h.data.filter((x) => x.ttd));
        if (h.data.length < h.per_halaman) break;
      }
      if (siap.length === 0) throw new Error('Belum ada draf yang ditandatangani Rektor.');
      const batch = siap.slice(0, MAKS_BATCH);
      const penanda = await sesi.penanda();
      const hash = await penanda.kirim({ to: j.kontrak, data: dataTerbitkan(batch) });
      const r = await api.terbit(hash);
      return `${r.terbit.length} ijazah tercatat di blockchain`;
    });

  async function tautanUntuk(x: Draf): Promise<string> {
    if (x.token_id === null) throw new Error('Ijazah belum tercatat');
    const { kunci } = await api.kunci(x.token_id);
    return tautanBerkunci(location.origin, x.token_id, kunci);
  }

  const aksiUtama: Aksi | null = !d
    ? null
    : d.status === 'DITANDATANGANI'
      ? { id: 'catat', label: `Catat ${Math.min(hitung.siap, MAKS_BATCH)} ijazah ke blockchain`, jalankan: () => void catat() }
      : d.status === 'TERBIT' || d.status === 'DICABUT'
        ? {
            id: 'buka',
            label: 'Buka tautan ijazah',

          }
        : d.status === 'DITOLAK'
          ? { id: 'ulang', label: 'Perbaiki dan kirim ulang', jalankan: () => location.assign(`/op/unggah?ulang=${d.id}`) }
          : null;

  const aksi: Aksi[] = [];
  if (d?.status === 'TERBIT') {
    aksi.push(
      {
        id: 'qr',
        label: 'Lembar QR',
        jalankan: () => void tautanUntuk(d).then((t) => setQr({ tautan: t, nama: d.nama, nomor: d.nomor_ijazah })).catch((e: unknown) => setKabar({ teks: pesan(e), nada: 'bad' })),
      },

        id: 'salin',
        label: 'Salin tautan berkunci',
        jalankan: () =>
          void tautanUntuk(d)
            .then((t) => navigator.clipboard?.writeText(t))
            .then(() => setKabar({ teks: 'Tautan berkunci disalin', nada: 'ok' }))
            .catch((e: unknown) => setKabar({ teks: pesan(e), nada: 'bad' })),
      },
      { id: 'cabut', label: 'Cabut ijazah…', bahaya: true, jalankan: () => setCabut(true) },
    );
  }
  if (hitung.siap > 0 && d?.status !== 'DITANDATANGANI') {
    aksi.push({ id: 'catat', label: `Catat ${Math.min(hitung.siap, MAKS_BATCH)} ijazah ke blockchain`, jalankan: () => void catat() });
  }
  aksi.push({ id: 'unggah', label: 'Unggah draf baru', jalankan: () => location.assign('/op/unggah') });

  const item: Item[] = useMemo(
    () =>
      daftar.map((x) => {
        const t = tampilanDraf(x);
        return { id: x.id, judul: x.nama, ket: t.ket, nada: t.nada, ikon: t.ikon, coret: t.coret, grup: labelHari(x.dibuat) };

  );

        <Segel nada={nadaSegelDraf(d.status)} />

      <div className="hud">Informasi</div>

            </button>
```

```tsx
  tahap: Tahap;
  pesan: string;
  draf: DrafBaru | null;
}

const KOSONG: DataLulusan & { email: string } = { nama: '', nim: '', prodi: '', gelar: '', nomor_ijazah: '', tanggal_lulus: '', email: '' };

const LABEL: Record<keyof typeof KOSONG, string> = {
  nama: 'Nama lulusan',
  nim: 'NIM',
  prodi: 'Program studi',
  gelar: 'Gelar',
  nomor_ijazah: 'Nomor ijazah',
  tanggal_lulus: 'Tanggal lulus',
  email: 'Email alumni',
};

const KET: Record<Tahap, { teks: string; nada: string }> = {
  antre: { teks: 'Antre', nada: 'redup' },
  menyegel: { teks: 'Menyegel & mengunggah ke IPFS…', nada: 'biru' },
  siap: { teks: 'Keccak ✓ · AES ✓ · IPFS ✓', nada: 'ok' },
  galat: { teks: '', nada: 'bad' },
  terkirim: { teks: '↑ Terkirim ke Meja Rektor', nada: 'ok' },
};

async function bacaPdf(f: FileList | null): Promise<BerkasPdf[]> {
  return Promise.all([...(f ?? [])].map(async (x) => ({ nama: x.name, isi: new Uint8Array(await x.arrayBuffer()) })));
}

function Isi() {
  const { api, info, sesi } = useAplikasi();
  const ulang = new URLSearchParams(location.search).get('ulang');
  const [mode, setMode] = useState<'csv' | 'satu'>(ulang ? 'satu' : 'csv');
  const [namaCsv, setNamaCsv] = useState('');
  const [teksCsv, setTeksCsv] = useState<string | null>(null);
  const [pdf, setPdf] = useState<BerkasPdf[]>([]);
  const [baris, setBaris] = useState<Baris[]>([]);
  const [isian, setIsian] = useState(KOSONG);
  const [pdfSatu, setPdfSatu] = useState<Uint8Array | null>(null);
  const [kabar, setKabar] = useState<{ teks: string; nada?: 'ok' | 'bad' } | null>(null);
  const [sibuk, setSibuk] = useState(false);

  useEffect(() => {
    if (!ulang) return;
    api
      .detailDraf(ulang)
      .then((d) => {
        setIsian({ nama: d.nama, nim: d.nim, prodi: d.prodi, gelar: d.gelar, nomor_ijazah: d.nomor_ijazah, tanggal_lulus: d.tanggal_lulus, email: d.email });
        setKabar({ teks: `Ditolak Rektor: ${d.alasan_tolak ?? '-'}. Perbaiki lalu kirim ulang dengan PDF yang benar.`, nada: 'bad' });
      })
      .catch((e: unknown) => setKabar({ teks: e instanceof Error ? e.message : 'Draf tidak bisa dimuat', nada: 'bad' }));
  }, [api, ulang]);

  // Susun ulang baris setiap CSV atau kumpulan PDF berubah.
  useEffect(() => {
    if (teksCsv === null) return;
    let batal = false;
    void muatCore().then((core) => {
      if (batal) return;
      try {
        const h = JSON.parse(core.baca_csv(teksCsv)) as HasilCsv;
        const sah: Baris[] = cocokkanPdf(h.baris, pdf).map(({ baris: b, pdf: p }) => ({
          kunci: `b${b.nomor_baris}`,
          nama: b.data.nama,
          email: b.email,
          data: b.data,
          pdf: p?.isi ?? null,
          tahap: p ? 'antre' : 'galat',
          pesan: p ? '' : `PDF ${b.file_pdf} belum dipilih`,
          draf: null,
        }));
        const salah: Baris[] = h.galat.map((g) => ({
          kunci: `g${g.nomor_baris}`,
          nama: `Baris ${g.nomor_baris}`,
          email: '',
          data: null,
          pdf: null,
          tahap: 'galat',
          pesan: g.pesan,
          draf: null,
        }));
        setBaris([...sah, ...salah]);
        setKabar(null);
      } catch (e) {
        setBaris([]);
        setKabar({ teks: e instanceof Error ? e.message : String(e), nada: 'bad' });
      }
    });
    return () => {
      batal = true;
    };
  }, [teksCsv, pdf]);

  async function alat(): Promise<AlatUnggah> {
    const core = await muatCore();
    return {
      keccak: (b) => core.keccak256_hex(b) as `0x${string}`,
      segel: (k, n, dj, p) => core.segel_amplop(k, n, dj, p),
      acak: (n) => crypto.getRandomValues(new Uint8Array(n)),
      unggah: (nama, isi) => api.unggahIpfs(nama, isi),
      gambar: `${location.origin}/segel.svg`,
    };
  }

  const ubah = (k: string, p: Partial<Baris>) => setBaris((bs) => bs.map((b) => (b.kunci === k ? { ...b, ...p } : b)));

  async function kirimCsv() {
    const antre = baris.filter((b) => b.tahap === 'antre' || b.tahap === 'siap');
    if (antre.length === 0 || sibuk) return;
    setSibuk(true);
    setKabar({ teks: 'Menyiapkan draf…' });
    try {
      const a = await alat();
      const siap: { kunci: string; draf: DrafBaru }[] = [];
      for (const b of antre) {
        if (b.draf) {
          siap.push({ kunci: b.kunci, draf: b.draf });
          continue;
        }
        if (!b.data || !b.pdf) continue;
        ubah(b.kunci, { tahap: 'menyegel' });
        try {
          const draf = await siapkanDraf(b.data, b.email, b.pdf, a);
          ubah(b.kunci, { tahap: 'siap', draf });
          siap.push({ kunci: b.kunci, draf });
        } catch (e) {
          ubah(b.kunci, { tahap: 'galat', pesan: e instanceof Error ? e.message : String(e) });
        }
      }
      if (siap.length === 0) throw new Error('Tidak ada baris yang siap dikirim.');
      await api.buatDraf(siap.map((s) => s.draf));
      for (const s of siap) ubah(s.kunci, { tahap: 'terkirim' });
      setKabar({ teks: `${siap.length} draf terkirim ke Meja Rektor`, nada: 'ok' });
    } catch (e) {
      setKabar({ teks: e instanceof Error ? e.message : String(e), nada: 'bad' });
    } finally {
      setSibuk(false);
    }
  }

  async function kirimSatu(e: FormEvent) {
    e.preventDefault();
    if (!pdfSatu || sibuk) return;
    setSibuk(true);
    setKabar({ teks: 'Menyegel dan mengunggah ke IPFS…' });
    try {
      const { email, ...data } = isian;
      const draf = await siapkanDraf(data, email, pdfSatu, await alat());
      if (ulang) await api.kirimUlang(ulang, draf);
      else await api.buatDraf([draf]);
      setKabar({ teks: ulang ? 'Draf diperbaiki dan dikirim ulang ke Meja Rektor' : 'Draf terkirim ke Meja Rektor', nada: 'ok' });
      if (!ulang) {
        setIsian(KOSONG);
        setPdfSatu(null);
      }
    } catch (x) {
      setKabar({ teks: x instanceof Error ? x.message : String(x), nada: 'bad' });
    } finally {
      setSibuk(false);
    }
  }

  useEffect(() => {
    const tekan = (e: KeyboardEvent) => {
      if ((e.metaKey || e.ctrlKey) && e.key === 'Enter' && mode === 'csv') {
        e.preventDefault();
        void kirimCsv();
      }
    };
    window.addEventListener('keydown', tekan);
    return () => window.removeEventListener('keydown', tekan);
  });

  const jumlah = (t: Tahap) => baris.filter((b) => b.tahap === t).length;
  const bisaKirim = jumlah('antre') + jumlah('siap');

  return (
    <Kerangka
      peran="Pusaka Operator"
      kode={ulang ? 'Kirim ulang' : 'Draf baru'}
      status={mode === 'csv' ? `Batch · ${bisaKirim} / ${baris.length}` : 'Satu draf'}
      wallet={info.wallet[0]}
      dok={DOK_OPERATOR}
      keluar={() => void sesi.keluar().then(() => location.assign('/masuk'))}
    >
      <div className="jendela">
        <div className="jendela-cari">
          <span aria-hidden="true">⇪</span>
          {!ulang && (
            <>
              <button type="button" className="chip" aria-pressed={mode === 'csv'} onClick={() => setMode('csv')}>
                CSV + PDF
              </button>
              <button type="button" className="chip" aria-pressed={mode === 'satu'} onClick={() => setMode('satu')}>
                Satu draf
              </button>
            </>
          )}
          <span className="hud" style={{ marginLeft: 'auto' }}>
            {mode === 'csv' ? `${namaCsv || 'Belum ada CSV'} · ${pdf.length} PDF` : 'IPFS · terenkripsi'}
          </span>
        </div>

        {mode === 'csv' ? (
          <>
            <div className="formulir">
              <label>
                Berkas CSV (nama,nim,prodi,gelar,nomor_ijazah,tanggal_lulus,email,file_pdf)
                <input
                  type="file"
                  accept=".csv,text/csv"
                  data-testid="pilih-csv"
                  onChange={(e) => {
                    const f = e.currentTarget.files?.[0];
                    if (!f) return;
                    setNamaCsv(f.name);
                    void f.text().then(setTeksCsv);
                  }}
                />
              </label>
              <label>
                PDF ijazah (pilih semuanya sekaligus)
                <input type="file" accept="application/pdf,.pdf" multiple data-testid="pilih-pdf" onChange={(e) => void bacaPdf(e.currentTarget.files).then(setPdf)} />
              </label>
            </div>
            <div style={{ padding: '0 0 6px' }} role="list" aria-label="Baris draf">
              {baris.length === 0 && <p className="catatan jendela-grup">Pilih CSV lulusan dan PDF-nya. Satu batch maksimal 50 baris.</p>}
              {baris.map((b) => (
                <div key={b.kunci} className="baris-item" role="listitem" data-testid="baris-draf" style={{ cursor: 'default' }}>
                  <span className="ikon" data-nada={KET[b.tahap].nada} aria-hidden="true">
                    {b.tahap === 'galat' ? '!' : b.tahap === 'terkirim' || b.tahap === 'siap' ? '✓' : b.tahap === 'menyegel' ? '◐' : '○'}
                  </span>
                  <span className="teks">
                    <span>
                      {b.nama} <span style={{ color: 'var(--ink3)' }}>{b.email && `· ${b.email}`}</span>
                    </span>
                    {b.tahap === 'menyegel' && (
                      <span className="progres">
                        <i style={{ width: '60%' }} />
                      </span>
                    )}
                  </span>
                  <span className="ket" data-nada={KET[b.tahap].nada} style={{ textAlign: 'right' }}>
                    {b.tahap === 'galat' ? b.pesan : KET[b.tahap].teks}
                  </span>
                </div>
              ))}
            </div>
            <div className="jendela-bar">
              <span className="kiri" data-testid="kabar" data-nada={kabar?.nada}>
                {kabar?.teks ?? `${bisaKirim} siap · ${jumlah('menyegel')} proses · ${jumlah('galat')} perlu diperbaiki`}
              </span>
              <span className="kanan">
                <button type="button" disabled={sibuk || bisaKirim === 0} onClick={() => void kirimCsv()}>

                  <kbd>↵</kbd>

              </span>

                    value={isian[k]}

                PDF ijazah

                  accept="application/pdf,.pdf"
                  required
                  data-testid="pilih-pdf-satu"
                  onChange={(e) => {

            <div className="jendela-bar">

              </span>
              <span className="kanan">
                <button type="submit" disabled={sibuk || !pdfSatu}>
                  {ulang ? 'Kirim ulang ke Meja Rektor' : 'Kirim ke Meja Rektor'} <kbd>↵</kbd>
                </button>
              </span>
            </div>
          </form>
        )}
      </div>
    </Kerangka>
  );
}
```

```tsx
function Isi() {

  const [antre, setAntre] = useState<Draf[]>([]);

  const [sibuk, setSibuk] = useState(false);
  const [tolak, setTolak] = useState(false);

  const [pdf, setPdf] = useState<string | null>(null);

    }

            )}
            {pdf && <iframe className="pratinjau" style={{ display: 'block' }} src={pdf} title={`PDF ijazah ${kini.nama}`} />}
          </section>
        ) : (
          <section style={{ textAlign: 'center', marginTop: 24 }}>
            <div style={{ width: 200, margin: '0 auto' }}>
              <Segel nada="ok" />
            </div>
            <h1 className="judul" data-testid="meja-bersih">
              Meja bersih
            </h1>
            <p className="sub">Tidak ada ijazah yang menunggu tanda tangan.</p>
          </section>
        ))}

      {tab === 'cabut' && (
        <section aria-label="Permintaan pencabutan" style={{ maxWidth: 680, margin: '20px auto 0' }}>
          {cabut.length === 0 && <p className="catatan">Tidak ada permintaan pencabutan.</p>}
          <ul className="bukti">
            {cabut.map((c) => (
              <li key={c.id}>
                <span className="ikon" aria-hidden="true">
                  ⛓
                </span>
                <span className="nama">
                  {c.nama} · #{c.token_id}
                  <span className="ket" data-nada="bad">
                    Alasan: {c.alasan}
                  </span>
                </span>
                <button type="button" className="br" disabled={sibuk} onClick={() => void tandatanganiCabut(c)}>
                  Tanda tangani pencabutan
                </button>
              </li>
            ))}
          </ul>
        </section>
      )}

      <p className="catatan" data-testid="kabar" data-nada={kabar?.nada} style={{ textAlign: 'center', margin: '18px auto 0' }} aria-live="polite">
        {kabar?.teks ?? 'Tanda tangan EIP-712 mengikat penerima, sidik jari PDF, dan metadata; berlaku 7 hari.'}
      </p>
    </Kerangka>
  );
}

export default function Meja() {
  return (
    <PenyediaSesi>
      <Penjaga perlu="penandatangan">
        <Isi />
      </Penjaga>
    </PenyediaSesi>
  );
}
```

```tsx
import { useCallback, useEffect, useState } from 'react';
import Kerangka, { DOK_OPERATOR } from '../components/Kerangka';
import type { PermintaanCabut } from '../lib/api';
import { tanggal } from '../lib/format';
import { dataCabut } from '../lib/transaksi';
import PenyediaSesi from './sesi/PenyediaSesi';
import Penjaga, { useAplikasi } from './sesi/Penjaga';

const STATUS = {
  MENUNGGU_TTD: { ket: '○ Menunggu tanda tangan Rektor', nada: 'tunggu' },
  DITANDATANGANI: { ket: '◆ Ditandatangani · siap dikirim', nada: 'biru' },
  SELESAI: { ket: '↓ Dicabut di blockchain', nada: 'bad' },
} as const;

function Isi() {
  const { api, info, sesi, j } = useAplikasi();
  const [daftar, setDaftar] = useState<PermintaanCabut[]>([]);
  const [kabar, setKabar] = useState<{ teks: string; nada?: 'ok' | 'bad' } | null>(null);
  const [sibuk, setSibuk] = useState(false);

  const muat = useCallback(async () => setDaftar((await api.daftarCabut()).data), [api]);
  useEffect(() => {
    void muat().catch((e: unknown) => setKabar({ teks: e instanceof Error ? e.message : String(e), nada: 'bad' }));
  }, [muat]);

  async function kirim(c: PermintaanCabut) {
    setSibuk(true);
    setKabar({ teks: `Mengirim pencabutan #${c.token_id} ke blockchain…` });
    try {
      const p = await sesi.penanda();
      const hash = await p.kirim({ to: j.kontrak, data: dataCabut(c) });
      await api.selesaiCabut(c.id, hash);
      setKabar({ teks: `Ijazah #${c.token_id} dicabut. Semua jalur verifikasi kini menampilkan DICABUT.`, nada: 'ok' });
      await muat();
    } catch (e) {
      setKabar({ teks: e instanceof Error ? (e.message.split('\n')[0] ?? 'Gagal') : String(e), nada: 'bad' });
    } finally {
      setSibuk(false);
    }
  }

  return (
    <Kerangka
      peran="Pusaka Operator"
      kode="PSK-OP"
      status="Pencabutan"
      wallet={info.wallet[0]}
      dok={DOK_OPERATOR}
      keluar={() => void sesi.keluar().then(() => location.assign('/masuk'))}
    >
      <div className="jendela">
        <div className="jendela-cari">
          <span aria-hidden="true">⛓</span>
          <span>Permintaan pencabutan</span>
          <span className="hud" style={{ marginLeft: 'auto' }}>
            {daftar.length} permintaan
          </span>
        </div>
        <div style={{ padding: '6px 0' }}>
          {daftar.length === 0 && <p className="catatan jendela-grup">Belum ada permintaan. Cabut ijazah dari Buku Induk lewat menu Aksi.</p>}
          {daftar.map((c) => (
            <div key={c.id} className="baris-item" style={{ cursor: 'default' }} data-testid="baris-cabut">
              <span className="ikon" data-nada={STATUS[c.status].nada} aria-hidden="true">
                ⛓
              </span>
              <span className="teks">
                <span>
                  {c.nama} · #{c.token_id}
                </span>
                <span className="ket" data-nada={STATUS[c.status].nada}>
                  {STATUS[c.status].ket} · {tanggal(Date.parse(c.dibuat) / 1000)}
                </span>
              </span>
              {c.status === 'DITANDATANGANI' && (
                <button type="button" className="br" data-utama disabled={sibuk} onClick={() => void kirim(c)}>
                  Kirim pencabutan ke blockchain
                </button>
              )}
            </div>
          ))}
        </div>
        <div className="jendela-bar">
          <span className="kiri" data-testid="kabar" data-nada={kabar?.nada}>
            {kabar?.teks ?? 'Alasan pencabutan ikut dicatat permanen di blockchain.'}
          </span>
        </div>
      </div>
    </Kerangka>
  );
}

export default function CabutOp() {
  return (
    <PenyediaSesi>
      <Penjaga perlu="operator">
        <Isi />
      </Penjaga>
    </PenyediaSesi>
  );
}
```
