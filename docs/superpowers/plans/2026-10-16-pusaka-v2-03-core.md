# PUSAKA v2 · Rencana 03 — Crate `pusaka-core` (native + WASM)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Satu crate Rust tanpa I/O yang menjadi sumber kebenaran logika kripto PUSAKA: Keccak-256, amplop terenkripsi AES-256-GCM, hash EIP-712, dan pembacaan CSV lulusan. Crate ini dipakai backend (native) dan peramban (WASM).

**Architecture:** Modul kecil dengan satu tanggung jawab: `heks` (konversi hex), `hash`, `amplop`, `eip712`, `csv_lulusan`. Semua fungsi murni dan deterministik; keacakan (kunci, nonce) disuplai pemanggil. Modul `wasm` (fitur `wasm`) membungkusnya dengan `wasm-bindgen`, dan struktur kompleks dikirim sebagai string JSON.

**Tech Stack:** Rust 2024, tiny-keccak 2, aes-gcm 0.10 (tanpa getrandom), csv 1, serde/serde_json, thiserror 2, hex 0.4, wasm-bindgen 0.2, wasm-pack.

**Spec:** `docs/superpowers/specs/2026-10-16-pusaka-v2-design.md` (bagian 6, 7.1, 11; tahap 3). Vektor acuan: `docs/superpowers/plans/2026-10-16-pusaka-v2-00-peta-jalan.md`.

## Global Constraints

- Kerjakan setelah rencana 01 di-merge. Branch `feat/pusaka-v2-core` dari `main`. Tanpa atribusi AI di commit/PR.
- Tidak ada I/O, waktu, atau RNG di crate ini. Tidak ada `unwrap`/`expect`/`panic` di kode non-tes.
- Format amplop persis: `0x01 ‖ nonce(12) ‖ AES-256-GCM( u32BE(panjang header) ‖ header JSON ‖ PDF )`, tag 16 byte di akhir ciphertext. Kunci 32 byte.
- Header JSON berisi tepat field `nama, nim, prodi, gelar, nomor_ijazah, tanggal_lulus`; maks 16 KiB.
- EIP-712 domain `name "PUSAKA"`, `version "2"`; typehash sama persis dengan rencana 02.
- Kolom CSV persis dan berurutan: `nama,nim,prodi,gelar,nomor_ijazah,tanggal_lulus,email,file_pdf`; maks 50 baris data.
- WASM: `opt-level = "z"`; output paket di `web/src/wasm/` (generated, di-commit).

## Review Focus

- CSV dari Excel sering diawali BOM UTF-8 dan memakai CRLF → `bom_dan_crlf_diterima` (Task 5).
- Nama dengan koma dan karakter non-ASCII (mis. "Ni Luh Putu Ayu, S.Kom", "Ñañez") tetap utuh setelah segel → buka → `roundtrip_unicode_dan_koma` (Task 3).
- Amplop yang dipotong atau satu bitnya dibalik harus gagal dengan galat bertipe, bukan panic → `amplop_terpotong` dan `satu_bit_dibalik_gagal` (Task 3).
- NIM atau nomor ijazah ganda dalam satu CSV dilaporkan per baris, dan baris lain tetap diproses → `nim_ganda_dilaporkan` (Task 5).
- Alamat hex dengan huruf campuran (checksum EIP-55) atau tanpa `0x` diterima, sedangkan panjang yang salah ditolak → `alamat_berbagai_bentuk` (Task 1).

//! Keccak-256 (varian Ethereum, bukan SHA3-256 NIST).

use tiny_keccak::{Hasher, Keccak};

pub fn keccak256(data: &[u8]) -> [u8; 32] {
    let mut k = Keccak::v256();
    k.update(data);
    let mut out = [0u8; 32];
    k.finalize(&mut out);
    out
}
```

//! Konversi hex untuk hash dan alamat. Prefiks `0x` opsional, huruf besar/kecil diterima.

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum GalatHeks {
    #[error("bukan string hex")]
    BukanHex,
    #[error("panjang salah: harus {harus} byte, dapat {dapat}")]
    PanjangSalah { harus: usize, dapat: usize },
}

pub fn ke_hex(b: &[u8]) -> String {
    format!("0x{}", hex::encode(b))
}

fn tetap<const N: usize>(s: &str) -> Result<[u8; N], GalatHeks> {
    let s = s.strip_prefix("0x").or_else(|| s.strip_prefix("0X")).unwrap_or(s);
    let byte = hex::decode(s).map_err(|_| GalatHeks::BukanHex)?;
    let dapat = byte.len();
    byte.try_into().map_err(|_| GalatHeks::PanjangSalah { harus: N, dapat })
}

pub fn dari_hex32(s: &str) -> Result<[u8; 32], GalatHeks> {
    tetap::<32>(s)
}

pub fn alamat(s: &str) -> Result<[u8; 20], GalatHeks> {
    tetap::<20>(s)
}
```

```rust
//! Amplop terenkripsi berkas ijazah:
//! `0x01 ‖ nonce(12) ‖ AES-256-GCM( u32BE(panjang header) ‖ header JSON ‖ PDF )`.

use aes_gcm::aead::{Aead, KeyInit};
use aes_gcm::{Aes256Gcm, Key, Nonce};
use serde::{Deserialize, Serialize};

pub const VERSI: u8 = 1;
pub const PANJANG_NONCE: usize = 12;
pub const PANJANG_TAG: usize = 16;
pub const MAKS_HEADER: usize = 16 * 1024;

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct DataLulusan {
    pub nama: String,
    pub nim: String,
    pub prodi: String,
    pub gelar: String,
    pub nomor_ijazah: String,
    pub tanggal_lulus: String,
}

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct IsiAmplop {
    pub data: DataLulusan,
    pub pdf: Vec<u8>,
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum GalatAmplop {
    #[error("amplop terlalu pendek")]
    TerlaluPendek,
    #[error("versi amplop {0} tidak dikenal")]
    VersiTidakDikenal(u8),
    #[error("kunci salah atau amplop rusak")]
    GagalDekripsi,
    #[error("header amplop rusak")]
    HeaderRusak,
    #[error("data lulusan terlalu besar")]
    HeaderTerlaluBesar,
    #[error("enkripsi gagal")]
    GagalEnkripsi,
}

fn cipher(kunci: &[u8; 32]) -> Aes256Gcm {
    Aes256Gcm::new(Key::<Aes256Gcm>::from_slice(kunci))
}

pub fn segel(
    kunci: &[u8; 32],
    nonce: &[u8; PANJANG_NONCE],
    data: &DataLulusan,
    pdf: &[u8],
) -> Result<Vec<u8>, GalatAmplop> {
    let header = serde_json::to_vec(data).map_err(|_| GalatAmplop::HeaderRusak)?;
    if header.len() > MAKS_HEADER {
        return Err(GalatAmplop::HeaderTerlaluBesar);
    }
    let panjang = u32::try_from(header.len()).map_err(|_| GalatAmplop::HeaderTerlaluBesar)?;
    let mut isi = Vec::with_capacity(4 + header.len() + pdf.len());
    isi.extend_from_slice(&panjang.to_be_bytes());
    isi.extend_from_slice(&header);
    isi.extend_from_slice(pdf);

    let rahasia = cipher(kunci)
        .encrypt(Nonce::from_slice(nonce), isi.as_slice())
        .map_err(|_| GalatAmplop::GagalEnkripsi)?;
    let mut out = Vec::with_capacity(1 + PANJANG_NONCE + rahasia.len());
    out.push(VERSI);
    out.extend_from_slice(nonce);
    out.extend_from_slice(&rahasia);
    Ok(out)
}

pub fn buka(kunci: &[u8; 32], amplop: &[u8]) -> Result<IsiAmplop, GalatAmplop> {
    if amplop.len() < 1 + PANJANG_NONCE + PANJANG_TAG {
        return Err(GalatAmplop::TerlaluPendek);
    }
    if amplop[0] != VERSI {
        return Err(GalatAmplop::VersiTidakDikenal(amplop[0]));
    }
    let (nonce, rahasia) = amplop[1..].split_at(PANJANG_NONCE);
    let isi = cipher(kunci)
        .decrypt(Nonce::from_slice(nonce), rahasia)
        .map_err(|_| GalatAmplop::GagalDekripsi)?;

    let (awal, sisa) = isi.split_at_checked(4).ok_or(GalatAmplop::HeaderRusak)?;
    let panjang = u32::from_be_bytes([awal[0], awal[1], awal[2], awal[3]]) as usize;
    if panjang > MAKS_HEADER {
        return Err(GalatAmplop::HeaderRusak);
    }
    let (header, pdf) = sisa.split_at_checked(panjang).ok_or(GalatAmplop::HeaderRusak)?;
    let data = serde_json::from_slice(header).map_err(|_| GalatAmplop::HeaderRusak)?;
    Ok(IsiAmplop { data, pdf: pdf.to_vec() })
}
```

//! Hash EIP-712 untuk tanda tangan pejabat. Harus identik dengan `_hashTypedDataV4` di kontrak.

use crate::hash::keccak256;

pub const NAMA: &str = "PUSAKA";
pub const VERSI: &str = "2";

const TIPE_DOMAIN: &str =
    "EIP712Domain(string name,string version,uint256 chainId,address verifyingContract)";
const TIPE_PENERBITAN: &str =
    "Penerbitan(address penerima,bytes32 docHash,bytes32 metadataHash,uint64 batasWaktu)";
const TIPE_PENCABUTAN: &str = "Pencabutan(uint256 tokenId,bytes32 alasanHash,uint64 batasWaktu)";

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Domain {
    pub chain_id: u64,
    pub kontrak: [u8; 20],
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Penerbitan {
    pub penerima: [u8; 20],
    pub doc_hash: [u8; 32],
    pub metadata_hash: [u8; 32],
    pub batas_waktu: u64,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Pencabutan {
    pub token_id: u64,
    pub alasan_hash: [u8; 32],
    pub batas_waktu: u64,
}

/// Satu "word" ABI (32 byte) dari bilangan tak bertanda.
fn kata_u64(x: u64) -> [u8; 32] {
    let mut w = [0u8; 32];
    w[24..].copy_from_slice(&x.to_be_bytes());
    w
}

fn kata_alamat(a: &[u8; 20]) -> [u8; 32] {
    let mut w = [0u8; 32];
    w[12..].copy_from_slice(a);
    w
}

fn hash_kata(kata: &[[u8; 32]]) -> [u8; 32] {
    keccak256(&kata.concat())
}

pub fn domain_separator(d: &Domain) -> [u8; 32] {
    hash_kata(&[
        keccak256(TIPE_DOMAIN.as_bytes()),
        keccak256(NAMA.as_bytes()),
        keccak256(VERSI.as_bytes()),
        kata_u64(d.chain_id),
        kata_alamat(&d.kontrak),
    ])
}

pub fn struct_hash_penerbitan(p: &Penerbitan) -> [u8; 32] {
    hash_kata(&[
        keccak256(TIPE_PENERBITAN.as_bytes()),
        kata_alamat(&p.penerima),
        p.doc_hash,
        p.metadata_hash,
        kata_u64(p.batas_waktu),
    ])
}

fn struct_hash_pencabutan(c: &Pencabutan) -> [u8; 32] {
    hash_kata(&[
        keccak256(TIPE_PENCABUTAN.as_bytes()),
        kata_u64(c.token_id),
        c.alasan_hash,
        kata_u64(c.batas_waktu),
    ])
}

fn digest(d: &Domain, struktur: [u8; 32]) -> [u8; 32] {
    let mut m = Vec::with_capacity(66);
    m.extend_from_slice(&[0x19, 0x01]);
    m.extend_from_slice(&domain_separator(d));
    m.extend_from_slice(&struktur);
    keccak256(&m)
}

pub fn digest_penerbitan(d: &Domain, p: &Penerbitan) -> [u8; 32] {
    digest(d, struct_hash_penerbitan(p))
}

pub fn digest_pencabutan(d: &Domain, c: &Pencabutan) -> [u8; 32] {
    digest(d, struct_hash_pencabutan(c))
}

//! Pembaca CSV lulusan untuk unggah batch. Galat per baris dikumpulkan;
//! baris yang valid tetap dikembalikan.

use std::collections::HashSet;

use serde::Serialize;

use crate::amplop::DataLulusan;

pub const KOLOM: [&str; 8] =
    ["nama", "nim", "prodi", "gelar", "nomor_ijazah", "tanggal_lulus", "email", "file_pdf"];
pub const MAKS_BARIS: usize = 50;

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct BarisLulusan {
    pub nomor_baris: usize,
    pub data: DataLulusan,
    pub email: String,
    pub file_pdf: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize)]
pub struct GalatBaris {
    pub nomor_baris: usize,
    pub pesan: String,
}

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Default)]
pub struct HasilCsv {
    pub baris: Vec<BarisLulusan>,
    pub galat: Vec<GalatBaris>,
}

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum GalatCsv {
    #[error("berkas CSV kosong")]
    Kosong,
    #[error("kolom CSV harus: {}; ditemukan: {ditemukan}", KOLOM.join(","))]
    KolomSalah { ditemukan: String },
    #[error("maksimal {MAKS_BARIS} baris per batch, berkas berisi {0}")]
    TerlaluBanyak(usize),
    #[error("CSV rusak: {0}")]
    Rusak(String),
}

pub fn baca(teks: &str) -> Result<HasilCsv, GalatCsv> {
    let teks = teks.strip_prefix('\u{feff}').unwrap_or(teks);
    let mut rdr = csv::ReaderBuilder::new()
        .has_headers(true)
        .trim(csv::Trim::All)
        .flexible(true)
        .from_reader(teks.as_bytes());

    let kepala = rdr.headers().map_err(|e| GalatCsv::Rusak(e.to_string()))?.clone();
    if kepala.is_empty() || kepala.iter().all(str::is_empty) {
        return Err(GalatCsv::Kosong);
    }
    if kepala.len() != KOLOM.len() || kepala.iter().zip(KOLOM).any(|(a, b)| a != b) {
        return Err(GalatCsv::KolomSalah { ditemukan: kepala.iter().collect::<Vec<_>>().join(",") });
    }

    let rekaman: Vec<csv::StringRecord> = rdr
        .records()
        .collect::<Result<_, _>>()
        .map_err(|e| GalatCsv::Rusak(e.to_string()))?;
    let rekaman: Vec<_> = rekaman.into_iter().filter(|r| r.iter().any(|f| !f.is_empty())).collect();
    if rekaman.is_empty() {
        return Err(GalatCsv::Kosong);
    }
    if rekaman.len() > MAKS_BARIS {
        return Err(GalatCsv::TerlaluBanyak(rekaman.len()));
    }

    let mut hasil = HasilCsv::default();
    let mut nim_terpakai = HashSet::new();
    let mut nomor_terpakai = HashSet::new();
    for r in rekaman {
        let nomor_baris = r.position().map_or(0, |p| p.line() as usize);
        match periksa_baris(&r, nomor_baris, &mut nim_terpakai, &mut nomor_terpakai) {
            Ok(b) => hasil.baris.push(b),
            Err(pesan) => hasil.galat.push(GalatBaris { nomor_baris, pesan }),
        }
    }
    Ok(hasil)
}

fn periksa_baris(
    r: &csv::StringRecord,
    nomor_baris: usize,
    nim_terpakai: &mut HashSet<String>,
    nomor_terpakai: &mut HashSet<String>,
) -> Result<BarisLulusan, String> {
    let ambil = |i: usize| r.get(i).unwrap_or("").to_string();
    let [nama, nim, prodi, gelar, nomor_ijazah, tanggal_lulus, email, file_pdf] =
        std::array::from_fn(ambil);

    if let Some(k) = [&nama, &nim, &prodi, &gelar, &nomor_ijazah, &tanggal_lulus, &email, &file_pdf]
        .iter()
        .position(|v| v.is_empty())
    {
        return Err(format!("kolom {} kosong", KOLOM[k]));
    }
    if !nim.chars().all(|c| c.is_ascii_digit()) {
        return Err("NIM hanya boleh berisi angka".into());
    }
    if !tanggal_valid(&tanggal_lulus) {
        return Err("tanggal_lulus harus berformat YYYY-MM-DD".into());
    }
    if !email_valid(&email) {
        return Err("email tidak valid".into());
    }
    if !file_pdf.to_ascii_lowercase().ends_with(".pdf") {
        return Err("file_pdf harus berkas PDF".into());
    }
    if !nim_terpakai.insert(nim.clone()) {
        return Err(format!("NIM {nim} ganda di berkas ini"));
    }
    if !nomor_terpakai.insert(nomor_ijazah.clone()) {
        return Err(format!("nomor ijazah {nomor_ijazah} ganda di berkas ini"));
    }
    Ok(BarisLulusan {
        nomor_baris,
        data: DataLulusan { nama, nim, prodi, gelar, nomor_ijazah, tanggal_lulus },
        email,
        file_pdf,
    })
}

fn tanggal_valid(s: &str) -> bool {
    let b = s.as_bytes();
    if b.len() != 10 || b[4] != b'-' || b[7] != b'-' {
        return false;
    }
    let angka = |r: std::ops::Range<usize>| s[r].parse::<u32>().ok();
    match (angka(0..4), angka(5..7), angka(8..10)) {
        (Some(_), Some(m), Some(d)) => (1..=12).contains(&m) && (1..=31).contains(&d),
        _ => false,
    }
}

fn email_valid(s: &str) -> bool {
    match s.split_once('@') {
        Some((lokal, domain)) => {
            !lokal.is_empty()
                && !domain.contains('@')
                && domain.contains('.')
                && !domain.starts_with('.')
                && !domain.ends_with('.')
                && !s.chars().any(char::is_whitespace)
        }
        None => false,
    }
}

//! bilangan 64-bit menjadi `bigint` di JavaScript.

use wasm_bindgen::prelude::*;

use crate::amplop::{self, DataLulusan, PANJANG_NONCE};
use crate::csv_lulusan;
use crate::eip712::{self, Domain, Pencabutan, Penerbitan};
use crate::hash::keccak256;

fn galat(e: impl std::fmt::Display) -> JsError {

}

fn kunci32(b: &[u8]) -> Result<[u8; 32], JsError> {
    b.try_into().map_err(|_| JsError::new("kunci harus 32 byte"))
}

#[wasm_bindgen]
pub fn segel_amplop(kunci: &[u8], nonce: &[u8], data_json: &str, pdf: &[u8]) -> Result<Vec<u8>, JsError> {
    let kunci = kunci32(kunci)?;
    let nonce: [u8; PANJANG_NONCE] =
        nonce.try_into().map_err(|_| JsError::new("nonce harus 12 byte"))?;
    let data: DataLulusan = serde_json::from_str(data_json).map_err(galat)?;
    amplop::segel(&kunci, &nonce, &data, pdf).map_err(galat)
}

}

#[wasm_bindgen]
pub fn digest_penerbitan_hex(

    kontrak: &str,
    penerima: &str,
    doc_hash: &str,
    metadata_hash: &str,
    batas_waktu: u64,
) -> Result<String, JsError> {

    };

}
