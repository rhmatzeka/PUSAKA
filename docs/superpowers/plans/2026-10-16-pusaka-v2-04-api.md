# PUSAKA v2 — Rencana 04: `pusaka-api` + Postgres + Privy + Pinata

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Backend Rust lengkap untuk alur draf → tanda tangan pejabat → terbit → cabut, dengan autentikasi Privy, penyimpanan Postgres, unggah IPFS Pinata, dan pembacaan kontrak lewat JSON-RPC, teruji penuh tanpa akun luar.

**Architecture:** Crate `pusaka-api` (axum 0.8) memegang `Negara` (state) yang berisi pool Postgres dan tiga layanan luar di balik trait (`Privy`, `Ipfs`, `Rantai`). Implementasi HTTP asli diuji terhadap server tiruan lokal; handler diuji dengan layanan palsu + Postgres sementara (`#[sqlx::test]`). Logika kripto (EIP-712, pemulihan penanda tangan, Keccak) dipanggil dari `pusaka-core`, jadi hasilnya identik dengan peramban dan kontrak.

**Tech Stack:** Rust 2024, axum 0.8, sqlx 0.9 (Postgres, rustls-ring), reqwest 0.12 (rustls-ring), jsonwebtoken 11 (ES256, rust_crypto), k256 0.13, aes-gcm 0.10, chrono, uuid, async-trait; Docker `postgres:17-alpine` untuk tes lokal.

**Spec:** `docs/superpowers/specs/2026-10-16-pusaka-v2-design.md` (bagian 7.2, 7.3, 9, 10, 11)

**Branch:** `feat/pusaka-v2-api` dari `feat/pusaka-v2-core` (bertumpuk; PR ke `feat/pusaka-v2`).

## Global Constraints

- Tidak ada `unwrap`/`expect`/`panic!` di jalur request (`crates/pusaka-api/src/**`); tes boleh.
- Semua galat HTTP berbentuk JSON `{ "kode": "…", "pesan": "…" }` dengan status yang tepat; galat 500 tidak membocorkan detail.
- Logging memakai `tracing`; rahasia (`PRIVY_APP_SECRET`, `PINATA_JWT`, `KUNCI_MASTER`, `DATABASE_URL`) tidak pernah dicetak.
- Env wajib: `DATABASE_URL`, `PRIVY_APP_ID`, `PRIVY_APP_SECRET`, `PRIVY_VERIFICATION_KEY`, `PINATA_JWT`, `KUNCI_MASTER`, `RPC_URL`, `ALAMAT_KONTRAK`, `CHAIN_ID`.
- Batch draf maksimal 50; berkas IPFS maksimal 4 MiB (batas body fungsi Vercel 4,5 MB); alasan tolak/cabut 1–500 karakter.
- Token Privy: ES256, `iss = "privy.io"`, `aud = PRIVY_APP_ID`, `sub` = DID.
- Peran on-chain: `OPERATOR_ROLE = keccak256("OPERATOR_ROLE")`, `PENANDATANGAN_ROLE = keccak256("PENANDATANGAN_ROLE")`, admin = `0x00…00`.
- Kunci JSON request/response memakai `snake_case` (`batas_waktu`, `tx_hash`, `token_id`), konsisten dengan kolom CSV dan WASM.
- `cargo fmt --all --check` dan `cargo clippy --workspace --all-targets -- -D warnings` bersih.
- Tanpa atribusi AI di commit maupun PR; commit atas identitas `rhmatzeka`; `.env*` tidak di-commit (kecuali `.env.example`).

## Keputusan terhadap spec (dicatat di sini, diperbarui ke spec di Task 13)

1. **JSON-RPC manual, bukan alloy.** Backend hanya butuh `hasRole` dan `eth_getTransactionReceipt`. Memakai reqwest + `pusaka-core` menghindari ratusan crate alloy (build Vercel lebih cepat, binary lebih kecil). Pengkodean diuji terhadap nilai `cast`.
2. **Batas berkas 4 MiB**, bukan 5 MB: fungsi Vercel menolak body > 4,5 MB.
3. **Kunci JSON `snake_case`** (spec menulis `batasWaktu`, `txHash`).
4. **Endpoint tambahan `GET /api/cabut?status=`**: meja pejabat dan operator butuh daftar permintaan cabut.
5. **Status draf `DICABUT`** ditambahkan supaya daftar operator mencerminkan pencabutan.
6. **Kunci AES disimpan dengan AAD = id draf** sehingga kunci tidak bisa dipindah ke draf lain.
7. **Batas laju dihitung dari `audit_log`** (120 aksi tulis/menit/DID). Ini berlaku lintas instance serverless tanpa Redis.
8. **Migrasi dijalankan manual** (`cargo run -p pusaka-api -- migrasi`) dengan koneksi langsung Neon, bukan saat cold start (pooler Neon tidak cocok untuk advisory lock migrasi).

## Review Focus

1. Dua pejabat (atau dua tab) menyetujui draf yang sama bersamaan → tepat satu berhasil, satu `409`, hanya satu baris `tanda_tangan` (Task 10, `setujui_bersamaan_hanya_satu`).

//! Pemulihan alamat penanda tangan dari tanda tangan ECDSA secp256k1 (65 byte r‖s‖v).
//! Aturannya sama dengan `ECDSA.tryRecover` OpenZeppelin: s tinggi ditolak.

use k256::ecdsa::{RecoveryId, Signature, VerifyingKey};

use crate::hash::keccak256;

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum GalatTtd {
    #[error("tanda tangan harus 65 byte, dapat {0}")]
    PanjangSalah(usize),
    #[error("nilai v tidak valid: {0}")]
    VTidakValid(u8),
    #[error("nilai s terlalu tinggi (tanda tangan tidak kanonik)")]
    STinggi,
    #[error("tanda tangan tidak dapat dipulihkan")]
    GagalPulih,
}

/// Alamat Ethereum yang menandatangani `digest` (hash EIP-712 siap tanda tangan).
pub fn pulihkan(digest: &[u8; 32], sig: &[u8]) -> Result<[u8; 20], GalatTtd> {
    let sig: &[u8; 65] = sig
        .try_into()
        .map_err(|_| GalatTtd::PanjangSalah(sig.len()))?;
    let v = match sig[64] {
        27 | 28 => sig[64] - 27,
        0 | 1 => sig[64],
        v => return Err(GalatTtd::VTidakValid(v)),
    };
    let rs = Signature::from_slice(&sig[..64]).map_err(|_| GalatTtd::GagalPulih)?;
    if rs.normalize_s().is_some() {
        return Err(GalatTtd::STinggi);
    }
    let id = RecoveryId::from_byte(v).ok_or(GalatTtd::VTidakValid(sig[64]))?;
    let kunci =
        VerifyingKey::recover_from_prehash(digest, &rs, id).map_err(|_| GalatTtd::GagalPulih)?;
    let titik = kunci.to_encoded_point(false);
    let hash = keccak256(&titik.as_bytes()[1..]);
    let mut alamat = [0u8; 20];
    alamat.copy_from_slice(&hash[12..]);
    Ok(alamat)
}
```

use std::fmt;

use pusaka_core::heks;

/// Env yang wajib ada. Urutan ini juga urutan di pesan galat.
pub const ENV_WAJIB: [&str; 9] = [

    "PRIVY_VERIFICATION_KEY",
    "PINATA_JWT",
    "KUNCI_MASTER",
    "RPC_URL",
    "ALAMAT_KONTRAK",
    "CHAIN_ID",

    pub database_url: String,
    pub privy_app_id: String,
    pub privy_app_secret: String,
    /// PEM kunci publik ES256 dari dashboard Privy.
    pub privy_kunci_verifikasi: String,

            .field("chain_id", &self.chain_id)
            .field("alamat_kontrak", &heks::ke_hex(&self.alamat_kontrak))
            .finish_non_exhaustive()
    }

#[derive(Debug, Clone, PartialEq, Eq, thiserror::Error)]
pub enum GalatKonfigurasi {
    #[error("env belum diisi: {}", .0.join(", "))]
    Hilang(Vec<&'static str>),
    #[error("env {0} tidak valid: {1}")]
    TidakValid(&'static str, String),
}

impl Konfigurasi {
    pub fn dari_env() -> Result<Self, GalatKonfigurasi> {
        Self::dari(|k| std::env::var(k).ok())
    }

    /// `env` mengembalikan nilai mentah sebuah variabel; nilai kosong dianggap tidak ada.
    pub fn dari(env: impl Fn(&str) -> Option<String>) -> Result<Self, GalatKonfigurasi> {
        let ambil = |k: &str| env(k).map(|v| v.trim().to_owned()).filter(|v| !v.is_empty());
        let hilang: Vec<&'static str> =
            ENV_WAJIB.iter().copied().filter(|k| ambil(k).is_none()).collect();
        if !hilang.is_empty() {
            return Err(GalatKonfigurasi::Hilang(hilang));
        }
        let wajib = |k: &str| ambil(k).unwrap_or_default();

        let kunci_master = heks::dari_hex32(&wajib("KUNCI_MASTER"))
            .map_err(|e| GalatKonfigurasi::TidakValid("KUNCI_MASTER", e.to_string()))?;
        if kunci_master == [0; 32] {
            return Err(GalatKonfigurasi::TidakValid("KUNCI_MASTER", "tidak boleh nol".into()));
        }
        let alamat_kontrak = heks::alamat(&wajib("ALAMAT_KONTRAK"))
            .map_err(|e| GalatKonfigurasi::TidakValid("ALAMAT_KONTRAK", e.to_string()))?;
        let chain_id = wajib("CHAIN_ID")
            .parse::<u64>()
            .map_err(|e| GalatKonfigurasi::TidakValid("CHAIN_ID", e.to_string()))?;

        Ok(Self {
            database_url: wajib("DATABASE_URL"),
            privy_app_id: wajib("PRIVY_APP_ID"),
            privy_app_secret: wajib("PRIVY_APP_SECRET"),

            pinata_upload_url: ambil("PINATA_UPLOAD_URL")
                .unwrap_or_else(|| "https://uploads.pinata.cloud".into()),
            kunci_master,
            rpc_url: wajib("RPC_URL"),
            alamat_kontrak,
            chain_id,
        })
    }

//! Galat API. Setiap varian punya status HTTP dan kode tetap; badan selalu JSON `{kode, pesan}`.

use axum::Json;
use axum::http::StatusCode;
use axum::response::{IntoResponse, Response};
use serde::Serialize;

#[derive(Debug, thiserror::Error)]
pub enum Galat {
    #[error("{0}")]
    TidakTerautentikasi(String),
    #[error("{0}")]
    PeranTidakCukup(String),
    #[error("{0}")]
    TidakDitemukan(String),
    #[error("{0}")]
    InputTidakValid(String),
    #[error("{0}")]
    Konflik(String),
    #[error("{0}")]
    StatusTidakSesuai(String),
    #[error("berkas melebihi batas {0} byte")]
    TerlaluBesar(usize),
    #[error("terlalu banyak permintaan; coba lagi dalam satu menit")]
    TerlaluBanyak,
    #[error("{0}")]
    LayananLuar(String),
    #[error("konfigurasi server belum lengkap: {0}")]
    KonfigurasiTidakLengkap(String),
    #[error("basis data: {0}")]
    Basisdata(#[from] sqlx::Error),
    #[error("{0}")]
    Internal(String),
}

#[derive(Debug, Serialize)]
pub struct GalatJson {
    pub kode: &'static str,
    pub pesan: String,
}

impl Galat {
    pub fn kode(&self) -> &'static str {
        match self {
            Self::TidakTerautentikasi(_) => "TIDAK_TERAUTENTIKASI",
            Self::PeranTidakCukup(_) => "PERAN_TIDAK_CUKUP",
            Self::TidakDitemukan(_) => "TIDAK_DITEMUKAN",
            Self::InputTidakValid(_) => "INPUT_TIDAK_VALID",
            Self::Konflik(_) => "KONFLIK",
            Self::StatusTidakSesuai(_) => "STATUS_TIDAK_SESUAI",
            Self::TerlaluBesar(_) => "TERLALU_BESAR",
            Self::TerlaluBanyak => "TERLALU_BANYAK",
            Self::LayananLuar(_) => "LAYANAN_LUAR",
            Self::KonfigurasiTidakLengkap(_) => "KONFIGURASI_TIDAK_LENGKAP",
            Self::Basisdata(_) | Self::Internal(_) => "INTERNAL",
        }
    }

    pub fn status(&self) -> StatusCode {
        match self {
            Self::TidakTerautentikasi(_) => StatusCode::UNAUTHORIZED,
            Self::PeranTidakCukup(_) => StatusCode::FORBIDDEN,
            Self::TidakDitemukan(_) => StatusCode::NOT_FOUND,
            Self::InputTidakValid(_) => StatusCode::BAD_REQUEST,
            Self::Konflik(_) | Self::StatusTidakSesuai(_) => StatusCode::CONFLICT,
            Self::TerlaluBesar(_) => StatusCode::PAYLOAD_TOO_LARGE,
            Self::TerlaluBanyak => StatusCode::TOO_MANY_REQUESTS,
            Self::LayananLuar(_) => StatusCode::BAD_GATEWAY,
            Self::KonfigurasiTidakLengkap(_) => StatusCode::SERVICE_UNAVAILABLE,
            Self::Basisdata(_) | Self::Internal(_) => StatusCode::INTERNAL_SERVER_ERROR,
        }
    }
}

impl IntoResponse for Galat {
    fn into_response(self) -> Response {
        let pesan = match &self {
            Self::Basisdata(_) | Self::Internal(_) => {
                tracing::error!(galat = %self, "galat internal");
                "Terjadi kesalahan di server".to_owned()
            }
            Self::LayananLuar(_) => {
                tracing::warn!(galat = %self, "layanan luar gagal");
                self.to_string()
            }
            _ => self.to_string(),
        };
        (self.status(), Json(GalatJson { kode: self.kode(), pesan })).into_response()
    }
}

//! Extractor yang mengubah penolakan axum (teks biasa) menjadi `Galat` JSON.

use axum::Json;
use axum::extract::{FromRequest, FromRequestParts, Query, Request};
use axum::http::request::Parts;
use serde::de::DeserializeOwned;
use uuid::Uuid;

use crate::galat::Galat;

/// Badan JSON; galat urai → 400 INPUT_TIDAK_VALID.
pub struct JsonMasuk<T>(pub T);

impl<S: Send + Sync, T: DeserializeOwned> FromRequest<S> for JsonMasuk<T> {
    type Rejection = Galat;

    async fn from_request(req: Request, state: &S) -> Result<Self, Galat> {
        match Json::<T>::from_request(req, state).await {
            Ok(Json(isi)) => Ok(Self(isi)),
            Err(e) => Err(Galat::InputTidakValid(e.body_text())),
        }
    }
}

/// Parameter query; galat urai → 400 INPUT_TIDAK_VALID.
pub struct QueryMasuk<T>(pub T);

impl<S: Send + Sync, T: DeserializeOwned> FromRequestParts<S> for QueryMasuk<T> {
    type Rejection = Galat;

    async fn from_request_parts(parts: &mut Parts, _: &S) -> Result<Self, Galat> {
        Query::<T>::try_from_uri(&parts.uri)
            .map(|Query(isi)| Self(isi))
            .map_err(|e| Galat::InputTidakValid(e.body_text()))
    }
}

pub fn id_dari(s: &str) -> Result<Uuid, Galat> {
    Uuid::parse_str(s).map_err(|_| Galat::InputTidakValid("id harus UUID".into()))
}

pub fn token_dari(s: &str) -> Result<u64, Galat> {
    s.parse::<u64>()
        .ok()
        .filter(|t| i64::try_from(*t).is_ok())
        .ok_or_else(|| Galat::InputTidakValid("token_id harus bilangan bulat positif".into()))
}

//! Kunci AES ijazah disimpan terenkripsi dengan KUNCI_MASTER (AES-256-GCM).
//! Format: nonce 12 byte ‖ ciphertext 32 byte ‖ tag 16 byte. AAD = id draf, sehingga kunci
//! yang tersimpan tidak bisa dipindahkan ke draf lain.

use aes_gcm::aead::{Aead, Payload};
use aes_gcm::{Aes256Gcm, Key, KeyInit, Nonce};
use uuid::Uuid;

use crate::galat::Galat;

const PANJANG: usize = 12 + 32 + 16;

fn sandi(master: &[u8; 32]) -> Aes256Gcm {
    Aes256Gcm::new(Key::<Aes256Gcm>::from_slice(master))
}

pub fn bungkus(master: &[u8; 32], draf: Uuid, kunci: &[u8; 32]) -> Result<Vec<u8>, Galat> {
    let mut nonce = [0u8; 12];
    getrandom::fill(&mut nonce).map_err(|e| Galat::Internal(format!("getrandom: {e}")))?;
    let ct = sandi(master)
        .encrypt(Nonce::from_slice(&nonce), Payload { msg: kunci, aad: draf.as_bytes() })
        .map_err(|_| Galat::Internal("enkripsi kunci gagal".into()))?;
    Ok([nonce.as_slice(), &ct].concat())
}

pub fn buka(master: &[u8; 32], draf: Uuid, bungkus: &[u8]) -> Result<[u8; 32], Galat> {
    if bungkus.len() != PANJANG {
        return Err(Galat::Internal("panjang kunci tersimpan salah".into()));
    }
    let (nonce, ct) = bungkus.split_at(12);
    let polos = sandi(master)
        .decrypt(Nonce::from_slice(nonce), Payload { msg: ct, aad: draf.as_bytes() })
        .map_err(|_| Galat::Internal("kunci tersimpan tidak dapat dibuka".into()))?;
    polos
        .try_into()
        .map_err(|_| Galat::Internal("kunci tersimpan bukan 32 byte".into()))
}
```

use async_trait::async_trait;
use pusaka_core::hash::keccak256;
use pusaka_core::heks;
use serde_json::{Value, json};

use crate::galat::Galat;
use crate::layanan::{Log, Rantai, Receipt};

pub const PERAN_ADMIN: [u8; 32] = [0; 32];
const SELEKTOR_HAS_ROLE: [u8; 4] = [0x91, 0xd1, 0x48, 0x54];

pub fn peran_operator() -> [u8; 32] {
    keccak256(b"OPERATOR_ROLE")
}

pub fn peran_penandatangan() -> [u8; 32] {
    keccak256(b"PENANDATANGAN_ROLE")
}

pub fn topik_diterbitkan() -> [u8; 32] {
    keccak256(b"Diterbitkan(uint256,address,bytes32,address)")
}

pub fn topik_dicabut() -> [u8; 32] {
    keccak256(b"Dicabut(uint256,string)")
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Terbit {
    pub token_id: u64,
    pub penerima: [u8; 20],
    pub doc_hash: [u8; 32],
}

fn kata_ke_u64(w: &[u8; 32]) -> Option<u64> {
    if w[..24].iter().any(|b| *b != 0) {
        return None;
    }
    let mut b = [0u8; 8];
    b.copy_from_slice(&w[24..]);
    Some(u64::from_be_bytes(b))
}

fn kata_ke_alamat(w: &[u8; 32]) -> [u8; 20] {
    let mut a = [0u8; 20];
    a.copy_from_slice(&w[12..]);
    a
}

/// Event `Diterbitkan` yang dipancarkan kontrak PUSAKA (log kontrak lain diabaikan).
pub fn event_terbit(r: &Receipt, kontrak: &[u8; 20]) -> Vec<Terbit> {
    let topik = topik_diterbitkan();
    r.log
        .iter()
        .filter(|l| &l.alamat == kontrak && l.topik.len() == 4 && l.topik[0] == topik)
        .filter_map(|l| {
            Some(Terbit {
                token_id: kata_ke_u64(&l.topik[1])?,
                penerima: kata_ke_alamat(&l.topik[2]),
                doc_hash: l.topik[3],
            })
        })
        .collect()
}

/// `tokenId` dari event `Dicabut` kontrak PUSAKA.
pub fn event_cabut(r: &Receipt, kontrak: &[u8; 20]) -> Vec<u64> {
    let topik = topik_dicabut();
    r.log
        .iter()
        .filter(|l| &l.alamat == kontrak && l.topik.len() == 2 && l.topik[0] == topik)
        .filter_map(|l| kata_ke_u64(&l.topik[1]))
        .collect()
}

pub fn calldata_has_role(peran: &[u8; 32], akun: &[u8; 20]) -> Vec<u8> {
    let mut d = Vec::with_capacity(68);
    d.extend_from_slice(&SELEKTOR_HAS_ROLE);
    d.extend_from_slice(peran);
    d.extend_from_slice(&[0u8; 12]);
    d.extend_from_slice(akun);
    d
}

/// Receipt JSON-RPC → `Receipt`; `None` bila bentuknya tidak dikenal.
pub fn urai_receipt(v: &Value) -> Option<Receipt> {
    let status = v.get("status")?.as_str()?;
    let sukses = u64::from_str_radix(status.trim_start_matches("0x"), 16).ok()? == 1;
    let log = v
        .get("logs")?
        .as_array()?
        .iter()
        .map(|l| {
            Some(Log {
                alamat: heks::alamat(l.get("address")?.as_str()?).ok()?,
                topik: l
                    .get("topics")?
                    .as_array()?
                    .iter()
                    .map(|t| heks::dari_hex32(t.as_str()?).ok())
                    .collect::<Option<Vec<_>>>()?,
                data: hex::decode(l.get("data")?.as_str()?.trim_start_matches("0x")).ok()?,
            })
        })
        .collect::<Option<Vec<_>>>()?;
    Some(Receipt { sukses, log })
}

pub struct RantaiRpc {
    http: reqwest::Client,
    url: String,
    kontrak: [u8; 20],
}

impl RantaiRpc {
    pub fn baru(http: reqwest::Client, url: String, kontrak: [u8; 20]) -> Self {
        Self { http, url, kontrak }
    }

    async fn panggil(&self, metode: &str, params: Value) -> Result<Value, Galat> {
        let res = self
            .http
            .post(&self.url)
            .json(&json!({ "jsonrpc": "2.0", "id": 1, "method": metode, "params": params }))
            .send()
            .await
            .map_err(|e| Galat::LayananLuar(format!("RPC tidak terjangkau: {e}")))?;
        if !res.status().is_success() {
            return Err(Galat::LayananLuar(format!("RPC menjawab {}", res.status())));
        }
        let mut v: Value = res
            .json()
            .await
            .map_err(|e| Galat::LayananLuar(format!("jawaban RPC rusak: {e}")))?;
        if let Some(g) = v.get("error") {
            return Err(Galat::LayananLuar(format!("RPC galat: {g}")));
        }
        Ok(v["result"].take())
    }
}

    }

//! Klien REST Privy: wallet milik pengguna dan wallet tertanam alumni dari email.

use async_trait::async_trait;
use pusaka_core::heks;
use reqwest::{Method, RequestBuilder, StatusCode};
use serde::Deserialize;
use serde_json::json;

use crate::galat::Galat;
use crate::layanan::Privy;

pub struct PrivyHttp {
    http: reqwest::Client,
    url: String,
    app_id: String,
    secret: String,
}

#[derive(Deserialize)]
struct PenggunaPrivy {
    linked_accounts: Vec<Akun>,
}

#[derive(Deserialize)]
struct Akun {
    #[serde(rename = "type")]
    jenis: String,
    #[serde(default)]
    address: Option<String>,
    #[serde(default)]
    chain_type: Option<String>,
    #[serde(default)]
    connector_type: Option<String>,
}

/// Wallet Ethereum milik pengguna, berpasangan dengan penanda "tertanam" (dibuat Privy).
fn wallet_ethereum(p: &PenggunaPrivy) -> Vec<([u8; 20], bool)> {
    p.linked_accounts
        .iter()
        .filter(|a| a.jenis == "wallet" && a.chain_type.as_deref() == Some("ethereum"))
        .filter_map(|a| {
            let alamat = heks::alamat(a.address.as_deref()?).ok()?;
            Some((alamat, a.connector_type.as_deref() == Some("embedded")))
        })
        .collect()
}

/// Utamakan wallet tertanam; bila tidak ada, wallet Ethereum pertama.
fn wallet_utama(p: &PenggunaPrivy, email: &str) -> Result<[u8; 20], Galat> {
    let w = wallet_ethereum(p);
    w.iter()
        .find(|(_, tertanam)| *tertanam)
        .or_else(|| w.first())
        .map(|(a, _)| *a)
        .ok_or_else(|| Galat::Konflik(format!("akun Privy {email} belum punya wallet Ethereum")))
}

impl PrivyHttp {
    pub fn baru(http: reqwest::Client, url: String, app_id: String, secret: String) -> Self {
        Self { http, url, app_id, secret }
    }

    fn minta(&self, metode: Method, jalur: &str) -> RequestBuilder {
        self.http
            .request(metode, format!("{}{jalur}", self.url.trim_end_matches('/')))
            .basic_auth(&self.app_id, Some(&self.secret))
            .header("privy-app-id", &self.app_id)
    }

    /// Kirim permintaan; 404 → `None`, sukses → isi, selain itu galat layanan luar.
    async fn kirim(&self, rb: RequestBuilder) -> Result<Option<PenggunaPrivy>, Galat> {
        let res = rb
            .send()
            .await
            .map_err(|e| Galat::LayananLuar(format!("Privy tidak terjangkau: {e}")))?;
        match res.status() {
            StatusCode::NOT_FOUND => Ok(None),
            s if s.is_success() => res
                .json()
                .await
                .map(Some)
                .map_err(|e| Galat::LayananLuar(format!("jawaban Privy rusak: {e}"))),
            s => Err(Galat::LayananLuar(format!("Privy menjawab {s}"))),
        }
    }

    async fn cari_email(&self, email: &str) -> Result<Option<PenggunaPrivy>, Galat> {
        self.kirim(
            self.minta(Method::POST, "/v1/users/email/address")
                .json(&json!({ "address": email })),
        )
        .await
    }
}

impl Privy for PrivyHttp {
    async fn wallet_pengguna(&self, did: &str) -> Result<Vec<[u8; 20]>, Galat> {

    async fn wallet_alumni(&self, email: &str) -> Result<[u8; 20], Galat> {

            Err(e) => Err(e),
        }
    }

//! Klien Pinata v3: unggah berkas ke IPFS publik.

use async_trait::async_trait;
use reqwest::multipart::{Form, Part};
use serde::Deserialize;

use crate::galat::Galat;
use crate::layanan::Ipfs;

pub struct PinataHttp {
    http: reqwest::Client,
    url: String,
    jwt: String,
}

#[derive(Deserialize)]
struct Jawaban {
    data: DataJawaban,
}

#[derive(Deserialize)]
struct DataJawaban {
    cid: String,
}

impl PinataHttp {
    pub fn baru(http: reqwest::Client, url: String, jwt: String) -> Self {
        Self { http, url, jwt }
    }
}

#[async_trait]
impl Ipfs for PinataHttp {
    async fn unggah(&self, nama: &str, isi: Vec<u8>) -> Result<String, Galat> {
        let berkas = Part::bytes(isi)
            .file_name(nama.to_owned())
            .mime_str("application/octet-stream")
            .map_err(|e| Galat::Internal(format!("mime: {e}")))?;
        let form = Form::new()
            .part("file", berkas)
            .text("network", "public")
            .text("name", nama.to_owned());
        let res = self
            .http
            .post(format!("{}/v3/files", self.url.trim_end_matches('/')))
            .bearer_auth(&self.jwt)
            .multipart(form)
            .send()
            .await
            .map_err(|e| Galat::LayananLuar(format!("Pinata tidak terjangkau: {e}")))?;
        if !res.status().is_success() {
            return Err(Galat::LayananLuar(format!("Pinata menjawab {}", res.status())));
        }
        let j: Jawaban = res
            .json()
            .await
            .map_err(|e| Galat::LayananLuar(format!("jawaban Pinata rusak: {e}")))?;
        if j.data.cid.is_empty() {
            return Err(Galat::LayananLuar("Pinata tidak mengembalikan CID".into()));
        }
        Ok(j.data.cid)
    }
}

    pub receipt: Mutex<HashMap<[u8; 32], Receipt>>,
    pub panggilan_peran: AtomicUsize,
}

    pub fn beri(&self, peran: [u8; 32], akun: [u8; 20]) {
        self.peran.lock().unwrap().insert((peran, akun));
    }

    pub fn cabut_peran(&self, peran: [u8; 32], akun: [u8; 20]) {
        self.peran.lock().unwrap().remove(&(peran, akun));
    }

    pub fn pasang_receipt(&self, tx: [u8; 32], r: Receipt) {
        self.receipt.lock().unwrap().insert(tx, r);
    }
}

    async fn punya_peran(&self, peran: [u8; 32], akun: [u8; 20]) -> Result<bool, Galat> {
        self.panggilan_peran.fetch_add(1, Ordering::SeqCst);
        Ok(self.peran.lock().unwrap().contains(&(peran, akun)))
    }

    async fn receipt(&self, tx: [u8; 32]) -> Result<Option<Receipt>, Galat> {
        Ok(self.receipt.lock().unwrap().get(&tx).cloned())
    }

struct Klaim<'a> {
    sub: &'a str,
    aud: &'a str,
    iss: &'a str,
    sid: &'a str,
    iat: i64,
    exp: i64,
}

pub fn token_khusus(did: &str, aud: &str, iss: &str, umur_detik: i64, pem: &str) -> String {
    let kini = chrono::Utc::now().timestamp();
    let klaim = Klaim { sub: did, aud, iss, sid: "sesi-uji", iat: kini, exp: kini + umur_detik };
    encode(&Header::new(Algorithm::ES256), &klaim, &EncodingKey::from_ec_pem(pem.as_bytes()).unwrap())
        .unwrap()
}

pub fn token(did: &str) -> String {
    token_khusus(did, APP_ID, "privy.io", 600, KUNCI_JWT)
}

async fn jawab(app: &Router, req: Request<Body>) -> (StatusCode, Value) {
    let res = app.clone().oneshot(req).await.unwrap();
    let status = res.status();
    let b = res.into_body().collect().await.unwrap().to_bytes();
    let v = if b.is_empty() {
        Value::Null
    } else {
        serde_json::from_slice(&b)
            .unwrap_or_else(|_| json!({ "mentah": String::from_utf8_lossy(&b) }))
    };
    (status, v)
}

pub async fn panggil(
    app: &Router,
    metode: &str,
    uri: &str,
    token: Option<&str>,
    badan: Option<Value>,
) -> (StatusCode, Value) {
    let mut r = Request::builder().method(metode).uri(uri);
    if let Some(t) = token {
        r = r.header("authorization", format!("Bearer {t}"));
    }
    let req = match badan {
        Some(b) => r.header("content-type", "application/json").body(Body::from(b.to_string())),
        None => r.body(Body::empty()),
    };
    jawab(app, req.unwrap()).await
}

pub async fn panggil_mentah(app: &Router, uri: &str, token: Option<&str>, isi: Vec<u8>) -> (StatusCode, Value) {
    let mut r = Request::post(uri).header("content-type", "application/octet-stream");
    if let Some(t) = token {
        r = r.header("authorization", format!("Bearer {t}"));
    }
    jawab(app, r.body(Body::from(isi)).unwrap()).await
}

pub fn tanda_tangani(kunci_hex: &str, digest: &[u8; 32]) -> String {
    let k = SigningKey::from_slice(&hex::decode(kunci_hex).unwrap()).unwrap();
    let (sig, id) = k.sign_prehash_recoverable(digest).unwrap();
    let mut b = sig.to_bytes().to_vec();
    b.push(27 + id.to_byte());
    ke_hex(&b)
}

        let kunci = DecodingKey::from_ec_pem(pem.as_bytes()).map_err(|e| e.to_string())?;
        let mut validasi = Validation::new(Algorithm::ES256);
        validasi.set_audience(&[app_id]);
        validasi.set_issuer(&["privy.io"]);
        validasi.set_required_spec_claims(&["exp", "aud", "iss", "sub"]);
        Ok(Self { kunci, validasi })
    }

    /// DID pengguna bila token sah.
    pub fn periksa(&self, token: &str) -> Result<String, Galat> {
        decode::<Klaim>(token, &self.kunci, &self.validasi)
            .map(|d| d.claims.sub)
            .map_err(|_| Galat::TidakTerautentikasi("token Privy tidak valid atau kedaluwarsa".into()))
    }
}

#[derive(Debug, Clone, Copy, Default, PartialEq, Eq, Serialize)]
pub struct Peran {
    pub admin: bool,
    pub operator: bool,
    pub penandatangan: bool,
}

#[derive(Debug, Clone)]
pub struct DataSesi {
    pub wallet: Vec<[u8; 20]>,
    pub peran: Peran,
}

pub struct CacheSesi {
    umur: Duration,
    isi: Mutex<HashMap<String, (Instant, DataSesi)>>,
}

impl CacheSesi {
    const MAKS_ENTRI: usize = 1000;

    pub fn baru(umur: Duration) -> Self {
        Self { umur, isi: Mutex::default() }
    }

    fn ambil(&self, did: &str) -> Option<DataSesi> {
        let isi = self.isi.lock().unwrap_or_else(PoisonError::into_inner);
        isi.get(did)
            .filter(|(t, _)| t.elapsed() < self.umur)
            .map(|(_, d)| d.clone())
    }

    fn simpan(&self, did: &str, data: DataSesi) {
        let mut isi = self.isi.lock().unwrap_or_else(PoisonError::into_inner);
        if isi.len() >= Self::MAKS_ENTRI {
            isi.retain(|_, (t, _)| t.elapsed() < self.umur);
            if isi.len() >= Self::MAKS_ENTRI {
                isi.clear();
            }
        }
        isi.insert(did.to_owned(), (Instant::now(), data));
    }
}

/// Pengguna yang sudah login.
#[derive(Debug, Clone)]
pub struct Pengguna {
    pub did: String,
    pub wallet: Vec<[u8; 20]>,
    pub peran: Peran,
}

impl Pengguna {
    pub fn wajib_operator(&self) -> Result<(), Galat> {
        if self.peran.operator {
            Ok(())
        } else {
            Err(Galat::PeranTidakCukup("butuh peran operator BAAK".into()))
        }
    }

    pub fn wajib_penandatangan(&self) -> Result<(), Galat> {
        if self.peran.penandatangan {
            Ok(())
        } else {
            Err(Galat::PeranTidakCukup("butuh peran pejabat penanda tangan".into()))
        }
    }

    pub fn wajib_operator_atau_penandatangan(&self) -> Result<(), Galat> {
        if self.peran.operator || self.peran.penandatangan {
            Ok(())
        } else {
            Err(Galat::PeranTidakCukup("butuh peran operator atau pejabat".into()))
        }
    }

    pub fn punya_wallet(&self, alamat: &[u8; 20]) -> bool {
        self.wallet.contains(alamat)
    }
}

async fn muat_sesi(n: &Negara, did: &str) -> Result<DataSesi, Galat> {
    let wallet = n.privy.wallet_pengguna(did).await?;
    let (op, ttd) = (peran_operator(), peran_penandatangan());
    let mut peran = Peran::default();
    for w in &wallet {
        let (admin, operator, penandatangan) = tokio::try_join!(
            n.rantai.punya_peran(PERAN_ADMIN, *w),
            n.rantai.punya_peran(op, *w),
            n.rantai.punya_peran(ttd, *w),
        )?;
        peran.admin |= admin;
        peran.operator |= operator;
        peran.penandatangan |= penandatangan;
    }
    Ok(DataSesi { wallet, peran })
}

impl FromRequestParts<Negara> for Pengguna {
    type Rejection = Galat;

    async fn from_request_parts(parts: &mut Parts, n: &Negara) -> Result<Self, Galat> {
        let token = parts
            .headers
            .get(AUTHORIZATION)
            .and_then(|v| v.to_str().ok())
            .and_then(|v| v.strip_prefix("Bearer "))
            .ok_or_else(|| Galat::TidakTerautentikasi("header Authorization: Bearer wajib".into()))?;
        let did = n.token.periksa(token.trim())?;
        let data = match n.cache.ambil(&did) {
            Some(d) => d,
            None => {
                let d = muat_sesi(n, &did).await?;
                n.cache.simpan(&did, d.clone());
                d
            }
        };
        Ok(Self { did, wallet: data.wallet, peran: data.peran })
    }
}

use crate::auth::Pengguna;

use crate::galat::Galat;

use crate::negara::Negara;

/// Body fungsi Vercel dibatasi 4,5 MB; amplop = PDF + header + 29 byte.
pub const MAKS_BERKAS: usize = 4 * 1024 * 1024;

#[derive(Deserialize)]
pub struct Kueri {
    nama: String,
}

fn nama_sah(nama: &str) -> bool {
    (1..=100).contains(&nama.len())
        && !nama.starts_with('.')
        && nama.bytes().all(|b| b.is_ascii_alphanumeric() || matches!(b, b'.' | b'_' | b'-'))
}

/// `POST /api/ipfs?nama=…`: unggah amplop atau metadata (badan mentah) ke IPFS publik.
pub async fn unggah(
    State(n): State<Negara>,
    p: Pengguna,
    QueryMasuk(q): QueryMasuk<Kueri>,
    badan: Body,
) -> Result<(StatusCode, Json<Value>), Galat> {
    p.wajib_operator()?;
    if !nama_sah(&q.nama) {
        return Err(Galat::InputTidakValid(
            "nama berkas hanya boleh huruf, angka, titik, garis bawah, dan strip (maks 100)".into(),
        ));
    }
    db::cek_batas(&n.db, &p.did).await?;
    let isi = axum::body::to_bytes(badan, MAKS_BERKAS)
        .await
        .map_err(|_| Galat::TerlaluBesar(MAKS_BERKAS))?;
    if isi.is_empty() {
        return Err(Galat::InputTidakValid("berkas kosong".into()));
    }
    let ukuran = isi.len();
    let cid = n.ipfs.unggah(&q.nama, isi.to_vec()).await?;
    db::audit(&n.db, &p.did, "ipfs.unggah", &cid, json!({ "nama": q.nama, "ukuran": ukuran })).await?;
    Ok((StatusCode::CREATED, Json(json!({ "cid": cid, "uri": format!("ipfs://{cid}") }))))
}

use chrono::{Datelike, NaiveDate};

pub const MAKS_TEKS: usize = 200;
pub const MAKS_ALASAN: usize = 500;

pub struct DrafBaru {

    pub nama: String,

    pub prodi: String,
    pub gelar: String,
    pub nomor_ijazah: String,
    pub tanggal_lulus: NaiveDate,
    pub email: String,
    pub doc_hash: [u8; 32],
    pub uri: String,
    pub cid_amplop: String,
    pub kunci: [u8; 32],

fn teks(kolom: &str, v: &str) -> Result<String, String> {
    let v = v.trim();
    if v.is_empty() {
        return Err(format!("{kolom} wajib diisi"));
    }
    if v.chars().count() > MAKS_TEKS {
        return Err(format!("{kolom} maksimal {MAKS_TEKS} karakter"));
    }
    Ok(v.to_owned())
}

fn nim(v: &str) -> Result<String, String> {
    let v = v.trim();
    if v.is_empty() || v.len() > 20 || !v.bytes().all(|b| b.is_ascii_digit()) {
        return Err("nim harus 1–20 digit angka".into());
    }
    Ok(v.to_owned())
}

fn tanggal(v: &str) -> Result<NaiveDate, String> {
    let v = v.trim();
    let b = v.as_bytes();
    let bentuk = b.len() == 10
        && b.iter()
            .enumerate()
            .all(|(i, c)| if i == 4 || i == 7 { *c == b'-' } else { c.is_ascii_digit() });
    let t = bentuk
        .then(|| NaiveDate::parse_from_str(v, "%Y-%m-%d").ok())
        .flatten()
        .ok_or_else(|| "tanggal_lulus harus tanggal YYYY-MM-DD yang ada di kalender".to_owned())?;
    if t.year() < 1900 {
        return Err("tanggal_lulus minimal tahun 1900".into());
    }
    Ok(t)
}

fn email(v: &str) -> Result<String, String> {
    let v = v.trim().to_lowercase();
    let sah = v.len() <= 254
        && !v.chars().any(char::is_whitespace)
        && match v.split_once('@') {
            Some((lokal, domain)) => {
                !lokal.is_empty()
                    && !domain.contains('@')
                    && domain.contains('.')
                    && !domain.starts_with('.')
                    && !domain.ends_with('.')
            }
            None => false,
        };
    if sah { Ok(v) } else { Err("email tidak valid".into()) }
}

fn hash(kolom: &str, v: &str) -> Result<[u8; 32], String> {
    let h = heks::dari_hex32(v.trim()).map_err(|_| format!("{kolom} harus 32 byte hex"))?;
    if h == [0; 32] {
        return Err(format!("{kolom} tidak boleh nol"));
    }
    Ok(h)
}

fn uri(v: &str) -> Result<String, String> {
    let v = v.trim();
    let sah = v.len() <= MAKS_TEKS
        && v.len() > "ipfs://".len()
        && v.starts_with("ipfs://")
        && !v.chars().any(char::is_whitespace);
    if sah { Ok(v.to_owned()) } else { Err("uri harus berbentuk ipfs://<cid>".into()) }
}

fn cid(v: &str) -> Result<String, String> {
    let v = v.trim();
    if v.is_empty() || v.len() > 100 || !v.bytes().all(|b| b.is_ascii_alphanumeric()) {
        return Err("cid_amplop tidak valid".into());
    }
    Ok(v.to_owned())
}

pub fn sahkan(d: &DrafBaru) -> Result<DrafSah, String> {
    Ok(DrafSah {
        nama: teks("nama", &d.nama)?,
        nim: nim(&d.nim)?,
        prodi: teks("prodi", &d.prodi)?,
        gelar: teks("gelar", &d.gelar)?,
        nomor_ijazah: teks("nomor_ijazah", &d.nomor_ijazah)?,
        tanggal_lulus: tanggal(&d.tanggal_lulus)?,
        email: email(&d.email)?,
        doc_hash: hash("doc_hash", &d.doc_hash)?,
        uri: uri(&d.uri)?,
        cid_amplop: cid(&d.cid_amplop)?,
        kunci: hash("kunci", &d.kunci)?,
    })
}

pub fn alasan(v: &str) -> Result<String, String> {
    let v = v.trim();
    if v.is_empty() || v.chars().count() > MAKS_ALASAN {
        return Err(format!("alasan wajib diisi, maksimal {MAKS_ALASAN} karakter"));
    }

}

pub async fn daftar_draf(
    db: &PgPool,
    status: Option<&str>,
    cari: Option<&str>,
    halaman: i64,
) -> Result<Halaman, Galat> {
    // `\` adalah karakter escape bawaan ILIKE di Postgres.
    let pola = cari.map(|c| {
        format!("%{}%", c.replace('\\', "\\\\").replace('%', "\\%").replace('_', "\\_"))
    });
    let data = sqlx::query_as(concat!(
        pilih_draf!(),
        "where ($1::text is null or d.status = $1) and ($2::text is null or d.nama ilike $2 \
         or d.nim ilike $2 or d.nomor_ijazah ilike $2) order by d.dibuat desc, d.id \
         limit $3 offset $4"
    ))
    .bind(status)
    .bind(pola.as_deref())
    .bind(PER_HALAMAN)
    .bind((halaman - 1) * PER_HALAMAN)
    .fetch_all(db)
    .await?;
    let (total,): (i64,) = sqlx::query_as(
        "select count(*) from draf d where ($1::text is null or d.status = $1) and \
         ($2::text is null or d.nama ilike $2 or d.nim ilike $2 or d.nomor_ijazah ilike $2)",
    )
    .bind(status)
    .bind(pola.as_deref())
    .fetch_one(db)
    .await?;
    Ok(Halaman { data, total })
}

/// `POST /api/draf`: 1..50 draf; wallet alumni diambil/dibuat lewat Privy sebelum menyimpan.
pub async fn buat(
    State(n): State<Negara>,
    p: Pengguna,
    JsonMasuk(b): JsonMasuk<BuatDraf>,
) -> Result<(StatusCode, Json<Value>), Galat> {
    p.wajib_operator()?;
    if b.draf.is_empty() || b.draf.len() > MAKS_BATCH {
        return Err(Galat::InputTidakValid(format!("jumlah draf harus 1–{MAKS_BATCH}")));
    }
    let sah: Vec<DrafSah> = b
        .draf
        .iter()
        .enumerate()
        .map(|(i, d)| validasi::sahkan(d).map_err(|e| format!("draf[{i}]: {e}")))
        .collect::<Result<_, _>>()
        .map_err(Galat::InputTidakValid)?;
    let mut dilihat = HashMap::new();
    for (i, d) in sah.iter().enumerate() {
        if let Some(j) = dilihat.insert(d.doc_hash, i) {
            return Err(Galat::InputTidakValid(format!(
                "draf[{i}]: doc_hash sama dengan draf[{j}]"
            )));
        }
    }
    db::cek_batas(&n.db, &p.did).await?;

    let mut penerima = Vec::with_capacity(sah.len());
    for d in &sah {
        penerima.push(n.privy.wallet_alumni(&d.email).await?);
    }

    let mut tx = n.db.begin().await?;
    let mut hasil = Vec::with_capacity(sah.len());
    for (d, w) in sah.iter().zip(&penerima) {
        let id = Uuid::new_v4();
        db::sisip_draf(&mut *tx, id, d, w, &p.did).await?;
        db::simpan_kunci(&mut *tx, id, &kunci::bungkus(&n.kunci_master, id, &d.kunci)?).await?;
        hasil.push(json!({ "id": id, "penerima": ke_hex(w) }));
    }
    db::audit(&mut *tx, &p.did, "draf.buat", "", json!({ "jumlah": hasil.len() })).await?;
    tx.commit().await?;
    Ok((StatusCode::CREATED, Json(json!({ "draf": hasil }))))
}

/// `GET /api/draf?status=&cari=&halaman=`
pub async fn daftar(
    State(n): State<Negara>,
    p: Pengguna,
    QueryMasuk(q): QueryMasuk<KueriDaftar>,

}

/// `POST /api/draf/{id}/tolak`
pub async fn tolak(
    State(n): State<Negara>,
    p: Pengguna,

use chrono::{DateTime, Utc};
use pusaka_core::heks::ke_hex;
use pusaka_core::ttd;
use serde::Deserialize;

use crate::auth::Pengguna;
use crate::galat::Galat;
use crate::negara::Negara;
use crate::rantai::peran_penandatangan;

/// Batas waktu tanda tangan paling lama 30 hari (spec: bawaan 7 hari di antarmuka).
pub const MAKS_MASA_TTD: u64 = 30 * 24 * 60 * 60;
/// Sisa waktu minimal supaya operator sempat mengirim transaksi.
pub const JEDA_MIN: u64 = 60;

#[derive(Debug, Deserialize)]
pub struct Persetujuan {
    pub sig: String,
    pub batas_waktu: u64,
}

pub struct PenandaTangan {
    pub alamat: [u8; 20],
    pub sig: Vec<u8>,
}

pub fn sekarang() -> u64 {
    u64::try_from(Utc::now().timestamp()).unwrap_or(0)
}

pub fn cek_batas_waktu(batas: u64, kini: u64) -> Result<DateTime<Utc>, Galat> {
    if batas < kini.saturating_add(JEDA_MIN) {
        return Err(Galat::InputTidakValid(
            "batas_waktu sudah lewat atau kurang dari 1 menit lagi".into(),
        ));
    }
    if batas > kini.saturating_add(MAKS_MASA_TTD) {
        return Err(Galat::InputTidakValid("batas_waktu maksimal 30 hari dari sekarang".into()));
    }
    i64::try_from(batas)
        .ok()
        .and_then(|b| DateTime::from_timestamp(b, 0))
        .ok_or_else(|| Galat::InputTidakValid("batas_waktu tidak valid".into()))
}

/// Pulihkan penanda tangan `digest`, lalu wajibkan: wallet itu milik pengguna yang login
/// dan (dicek ulang on-chain, tanpa cache) memegang PENANDATANGAN_ROLE.
pub async fn pulihkan(
    n: &Negara,
    p: &Pengguna,
    digest: &[u8; 32],
    sig_hex: &str,
) -> Result<PenandaTangan, Galat> {
    let sig = hex::decode(sig_hex.trim().trim_start_matches("0x"))
        .map_err(|_| Galat::InputTidakValid("sig harus hex".into()))?;
    let alamat = ttd::pulihkan(digest, &sig)
        .map_err(|e| Galat::InputTidakValid(format!("tanda tangan tidak valid: {e}")))?;
    if !p.punya_wallet(&alamat) {
        return Err(Galat::PeranTidakCukup(format!(
            "tanda tangan berasal dari {} yang bukan wallet Anda",
            ke_hex(&alamat)
        )));
    }
    if !n.rantai.punya_peran(peran_penandatangan(), alamat).await? {
        return Err(Galat::PeranTidakCukup(
            "wallet penanda tangan tidak memegang PENANDATANGAN_ROLE".into(),
        ));
    }
    Ok(PenandaTangan { alamat, sig })
}

/// `POST /api/draf/{id}/setujui`: tanda tangan EIP-712 `Penerbitan` dari pejabat.
pub async fn setujui(
    State(n): State<Negara>,
    p: Pengguna,
    Path(id): Path<String>,
    JsonMasuk(b): JsonMasuk<Persetujuan>,
) -> Result<Json<Value>, Galat> {
    p.wajib_penandatangan()?;
    let id = id_dari(&id)?;
    let batas = ttd_rute::cek_batas_waktu(b.batas_waktu, ttd_rute::sekarang())?;
    db::cek_batas(&n.db, &p.did).await?;
    let d = db::ambil_draf(&n.db, id)
        .await?
        .ok_or_else(|| Galat::TidakDitemukan("draf tidak ditemukan".into()))?;
    if d.status != "MENUNGGU_TTD" {
        return Err(Galat::StatusTidakSesuai(format!(
            "draf berstatus {}, harus MENUNGGU_TTD",
            d.status
        )));
    }
    let penerbitan = Penerbitan {
        penerima: heks::alamat(&d.penerima)
            .map_err(|_| Galat::Internal("penerima tersimpan rusak".into()))?,
        doc_hash: d.doc_hash32()?,
        metadata_hash: keccak256(d.uri.as_bytes()),
        batas_waktu: b.batas_waktu,
    };
    let digest = eip712::digest_penerbitan(&n.domain, &penerbitan);
    let pt = ttd_rute::pulihkan(&n, &p, &digest, &b.sig).await?;

    let mut tx = n.db.begin().await?;
    db::sisip_ttd(&mut *tx, "penerbitan", id, &pt.alamat, &pt.sig, batas).await?;
    if !db::tandai_draf_ditandatangani(&mut *tx, id).await? {
        drop(tx);
        return Err(galat_status(&n, id, "MENUNGGU_TTD").await);
    }
    db::audit(&mut *tx, &p.did, "draf.setujui", &id.to_string(), json!({ "penanda_tangan": ke_hex(&pt.alamat) })).await?;
    tx.commit().await?;
    Ok(Json(json!({ "id": id, "status": "DITANDATANGANI", "penanda_tangan": ke_hex(&pt.alamat) })))
}

use axum::Json;
use axum::extract::State;
use pusaka_core::heks;
use serde::Deserialize;
use serde_json::{Value, json};

use crate::auth::Pengguna;
use crate::db;
use crate::galat::Galat;
use crate::masukan::JsonMasuk;
use crate::negara::Negara;
use crate::rantai;

#[derive(Deserialize)]
pub struct CatatTx {
    pub tx_hash: String,
}

/// Ambil receipt yang sukses; galat yang jelas bila belum ditambang atau revert.
pub(crate) async fn receipt_sukses(n: &Negara, tx_hash: &str) -> Result<crate::layanan::Receipt, Galat> {
    let tx = heks::dari_hex32(tx_hash)
        .map_err(|_| Galat::InputTidakValid("tx_hash harus 32 byte hex".into()))?;
    let r = n.rantai.receipt(tx).await?.ok_or_else(|| {
        Galat::StatusTidakSesuai("transaksi belum dikonfirmasi; coba lagi sebentar".into())
    })?;
    if !r.sukses {
        return Err(Galat::InputTidakValid("transaksi gagal (revert) di blockchain".into()));
    }
    Ok(r)
}

/// `POST /api/terbit`: baca receipt `terbitkan`/`terbitkanBatch`, tandai draf TERBIT.
pub async fn catat(
    State(n): State<Negara>,
    p: Pengguna,
    JsonMasuk(b): JsonMasuk<CatatTx>,
) -> Result<Json<Value>, Galat> {
    p.wajib_operator()?;
    db::cek_batas(&n.db, &p.did).await?;
    let r = receipt_sukses(&n, &b.tx_hash).await?;
    let event = rantai::event_terbit(&r, &n.domain.kontrak);
    if event.is_empty() {
        return Err(Galat::InputTidakValid(
            "transaksi tidak memuat event Diterbitkan dari kontrak PUSAKA".into(),
        ));
    }
    let mut tx = n.db.begin().await?;
    let mut terbit = Vec::with_capacity(event.len());
    let mut tidak_dikenal = 0usize;
    for e in &event {
        let token = i64::try_from(e.token_id)
            .map_err(|_| Galat::Internal("token_id melebihi i64".into()))?;
        match db::tandai_terbit(&mut *tx, &e.doc_hash, token).await? {
            Some((id, penerima)) => {
                if penerima != heks::ke_hex(&e.penerima) {
                    tracing::warn!(%id, %penerima, "penerima on-chain berbeda dengan draf");
                }
                terbit.push(json!({ "id": id, "token_id": e.token_id }));
            }
            None => tidak_dikenal += 1,
        }
    }
    db::audit(&mut *tx, &p.did, "draf.terbit", b.tx_hash.trim(), json!({ "jumlah": terbit.len(), "tidak_dikenal": tidak_dikenal })).await?;
    tx.commit().await?;
    Ok(Json(json!({ "terbit": terbit, "tidak_dikenal": tidak_dikenal })))
}

/// Permintaan → SELESAI dan draf → DICABUT. Kontrak sumber kebenaran: permintaan yang

pub async fn selesaikan_cabut(
    tx: &mut sqlx::PgConnection,
    id: Uuid,
    token_id: i64,
) -> Result<bool, Galat> {
    let r = sqlx::query(
        "update permintaan_cabut set status = 'SELESAI', diubah = now() \
         where id = $1 and status <> 'SELESAI'",
    )
    .bind(id)
    .execute(&mut *tx)
    .await?;
    if r.rows_affected() != 1 {
        return Ok(false);
    }
    sqlx::query("update draf set status = 'DICABUT', diubah = now() where token_id = $1")
        .bind(token_id)
        .execute(&mut *tx)
        .await?;
    Ok(true)

/// `POST /api/cabut`
pub async fn buat(
    State(n): State<Negara>,
    p: Pengguna,
    JsonMasuk(b): JsonMasuk<MintaCabut>,
) -> Result<(StatusCode, Json<Value>), Galat> {
    p.wajib_operator()?;
    let alasan = validasi::alasan(&b.alasan).map_err(Galat::InputTidakValid)?;
    let token = i64::try_from(b.token_id)
        .map_err(|_| Galat::InputTidakValid("token_id terlalu besar".into()))?;
    db::cek_batas(&n.db, &p.did).await?;
    match db::draf_dari_token(&n.db, token).await? {
        Some(d) if d.status == "TERBIT" => {}
        _ => {
            return Err(Galat::TidakDitemukan(
                "ijazah dengan token_id itu tidak ada atau sudah dicabut".into(),
            ));
        }
    }
    let id = Uuid::new_v4();
    let mut tx = n.db.begin().await?;
    db::sisip_cabut(&mut *tx, id, token, &alasan, &p.did).await?;
    db::audit(&mut *tx, &p.did, "cabut.buat", &id.to_string(), json!({ "token_id": token, "alasan": alasan })).await?;
    tx.commit().await?;
    Ok((StatusCode::CREATED, Json(json!({ "id": id }))))
}

/// `GET /api/cabut?status=`
pub async fn daftar(
    State(n): State<Negara>,
    p: Pengguna,
    QueryMasuk(q): QueryMasuk<KueriCabut>,
) -> Result<Json<Value>, Galat> {
    p.wajib_operator_atau_penandatangan()?;
    if let Some(s) = &q.status {
        if !db::STATUS_CABUT.contains(&s.as_str()) {
            return Err(Galat::InputTidakValid(format!(
                "status harus salah satu dari {}",
                db::STATUS_CABUT.join(", ")
            )));
        }
    }
    db::kedaluwarsakan(&n.db).await?;
    let data = db::daftar_cabut(&n.db, q.status.as_deref()).await?;
    Ok(Json(json!({ "data": data.iter().map(BarisCabut::ke_json).collect::<Vec<_>>() })))
}

/// `POST /api/cabut/{id}/setujui`: tanda tangan EIP-712 `Pencabutan`.
pub async fn setujui(
    State(n): State<Negara>,
    p: Pengguna,
    Path(id): Path<String>,
    JsonMasuk(b): JsonMasuk<Persetujuan>,
) -> Result<Json<Value>, Galat> {
    p.wajib_penandatangan()?;
    let id = id_dari(&id)?;
    let batas = ttd::cek_batas_waktu(b.batas_waktu, ttd::sekarang())?;
    db::cek_batas(&n.db, &p.did).await?;
    db::kedaluwarsakan(&n.db).await?;
    let c = ambil(&n, id).await?;
    if c.status != "MENUNGGU_TTD" {
        return Err(Galat::StatusTidakSesuai(format!(
            "permintaan berstatus {}, harus MENUNGGU_TTD",
            c.status
        )));
    }
    let pencabutan = Pencabutan {
        token_id: u64::try_from(c.token_id)
            .map_err(|_| Galat::Internal("token_id tersimpan negatif".into()))?,
        alasan_hash: keccak256(c.alasan.as_bytes()),
        batas_waktu: b.batas_waktu,
    };
    let digest = eip712::digest_pencabutan(&n.domain, &pencabutan);
    let pt = ttd::pulihkan(&n, &p, &digest, &b.sig).await?;
    let mut tx = n.db.begin().await?;
    db::sisip_ttd(&mut *tx, "pencabutan", id, &pt.alamat, &pt.sig, batas).await?;
    if !db::tandai_cabut_ditandatangani(&mut *tx, id).await? {
        drop(tx);
        return Err(galat_status(&n, id, "MENUNGGU_TTD").await);
    }
    db::audit(&mut *tx, &p.did, "cabut.setujui", &id.to_string(), json!({ "penanda_tangan": ke_hex(&pt.alamat) })).await?;
    tx.commit().await?;
    Ok(Json(json!({ "id": id, "status": "DITANDATANGANI", "penanda_tangan": ke_hex(&pt.alamat) })))
}

/// `POST /api/cabut/{id}/selesai`: cocokkan event `Dicabut` lalu tutup permintaan.
pub async fn selesai(
    State(n): State<Negara>,
    p: Pengguna,
    Path(id): Path<String>,
    JsonMasuk(b): JsonMasuk<CatatTx>,
) -> Result<Json<Value>, Galat> {
    p.wajib_operator()?;
    let id = id_dari(&id)?;
    db::cek_batas(&n.db, &p.did).await?;
    let c = ambil(&n, id).await?;
    let r = receipt_sukses(&n, &b.tx_hash).await?;
    let token = u64::try_from(c.token_id)
        .map_err(|_| Galat::Internal("token_id tersimpan negatif".into()))?;
    if !rantai::event_cabut(&r, &n.domain.kontrak).contains(&token) {
        return Err(Galat::InputTidakValid(format!(
            "transaksi tidak mencabut token {token} di kontrak PUSAKA"
        )));
    }
    let mut tx = n.db.begin().await?;
    if !db::selesaikan_cabut(&mut tx, id, c.token_id).await? {
        drop(tx);
        return Err(galat_status(&n, id, "MENUNGGU_TTD atau DITANDATANGANI").await);
    }
    db::audit(&mut *tx, &p.did, "cabut.selesai", &id.to_string(), json!({ "tx_hash": b.tx_hash.trim() })).await?;
    tx.commit().await?;
    Ok(Json(json!({ "id": id, "status": "SELESAI", "token_id": token })))
}
